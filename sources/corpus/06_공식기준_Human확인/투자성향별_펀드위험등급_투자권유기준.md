# 투자성향별 펀드 위험등급 투자권유 가능 기준

> 이 문서는 원문을 옮긴 것이 아니라, Human이 KB국민은행 공식 투자권유 기준으로 확인한 매핑을 **Human-confirmed Official Fact** 로 기록한 것이다 (`golden/HUMAN_DECISIONS.md` HD-2.1, 2026-09-01). 원문 문서 확보 시 이 파일을 원문 정리본으로 교체하고 Registry의 Status를 갱신한다.

## 상품 위험등급 (6단계)

| 등급 | 명칭 |
|---|---|
| 1등급 | 매우높은위험 |
| 2등급 | 높은위험 |
| 3등급 | 다소높은위험 |
| 4등급 | 보통위험 |
| 5등급 | 낮은위험 |
| 6등급 | 매우낮은위험 |

## 투자성향별 투자권유 가능 등급

| 투자성향 | 권유 가능 위험등급 |
|---|---|
| 안정형 | 6등급 |
| 안정추구형 | 5~6등급 |
| 위험중립형 | 4~6등급 |
| 적극투자형 | 3~6등급 |
| 공격투자형 | 1~6등급 |

## 해석 원칙

- 투자성향은 **최대 허용 위험수준의 제한**이며 최소 위험수준의 요구가 아니다. 공격투자형 고객도 6등급 상품을 선택할 수 있다.
- 이미 보유 중인 상품의 등급이 현재 성향의 허용 범위를 넘는 것 자체는 위반이 아니다. 기준은 신규 매수·교체 권유에 적용된다.
- 허용 범위를 넘는 상품을 고객이 스스로 원하는 경우의 절차(부적합 확인 등)는 이 기록의 범위 밖이며 공식 절차를 따른다.
