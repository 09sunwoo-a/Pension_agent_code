# 퇴직연금 펀드 9월 포트폴리오

*행 내 한 / KB 국민은행*

> *기대수익률과 위험은 과거 데이터를 수학/통계적으로 분석하여 산출하였으며, 자산배분 비중은 KB자산관리 전략위원회 결과를 기초로 블랙-리터만 모형을 활용하여 자산군간 상관관계와 변동성을 고려하여 제안하였음.*
> *(위 문구는 모든 페이지 상단에 반복 표기됨)*

## TDF 포트폴리오

- 투자자의 은퇴시점에 맞추어 생애주기에 따라 Glide-Path를 통해 포트폴리오를 자동 조정하는 자산배분 펀드
- 은퇴가 가까워질수록 주식 및 위험자산 비중을 축소하며 하나의 펀드로 글로벌 분산투자 및 위험관리 실행
- 60세 은퇴 가정시 포트폴리오 예시 : 「출생년도 + 60」에 해당되는 TDF 선택

- 원문 추출본의 중복 마침표 표기(`연0..2990%`, `연0..1977%`)와 공백 표기(`연0. 2839%`)는 보수율 값 자체를 바꾸지 않는 범위에서 `연0.2990%`, `연0.1977%`, `연0.2839%`로 정규화함

### (b) 이미지 판독 영역(검수 필요)

- **TDF 위험자산 비중 매트릭스의 열 정렬** : 수치값 자체는 텍스트로 추출되었으나, 각 운용사 값이 어느 TDF 빈티지(2020~2055) 열에 대응하는지는 도표 판독 결과임 → `⟨판독불확실⟩`
  - 특히 **NH-Amundi·교보악사·우리·키움** 4개 행은 8월호와 **값의 나열은 완전히 동일**한데 **열 위치만 한 칸 왼쪽으로** 다르게 판독됨(예: NH-Amundi 52.0 → 8월호는 TDF2030, 본 회차는 TDF2025).
  - 동일 열의 타 운용사 값과 대조하면 TDF2025 열의 통상 범위는 33.4~42.7%인데 본 회차 판독값 52.0·48.4는 이를 크게 벗어나므로, **8월호 정렬(한 칸 오른쪽)이 맞을 가능성**이 있음. 원본 도표 대조 권장
- **NH-Amundi 하나로단기채 합성총보수** : 본 회차 `연0.2839%` / 8월호 `연0.2939%` — 한 자리 숫자만 다름. 원본 대조 권장 → `⟨판독불확실⟩`
- **표 구조** : 자산배분 비중은 도넛 차트 이미지에서 판독하여 각 포트폴리오 머리말에 텍스트로 옮김
