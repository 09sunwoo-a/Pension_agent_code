## Knowledge Items

### K-001. TDF 선택 기준 — 빈티지 산식, 숫자 의미, H/UH, 라인업 수(as-of)
- **Knowledge (Source-derived)**: TDF 뒤 4자리 = 은퇴시점(Target Date). 계산법 **출생연도 + 예상 은퇴연령 = 은퇴시점**(예: 1990년생·60세 → 2050). 숫자가 작을수록 안전자산 비중↑, 클수록 위험자산↑ → 적극 운용 희망이면 큰 숫자, 안정적 관리 희망이면 작은 숫자. 헤지(H)는 환율 변동 위험을 줄이고, 언헤지(UH)는 환차익/손실이 그대로 반영. KB 라인업은 총 18종(2025.10) / 16개 운용사 시리즈 × 2020~2055(2026.08). 행내 자료: "60세 은퇴 가정 시 「출생년도 + 60」에 해당하는 TDF 선택".
- **Source / Location**: SRC-090 `04_KBthink_연금/04_TDF란.md` L24–52; SRC-094 `…/01_퇴직연금펀드_포트폴리오_2026.08.md` L10–11, L30
- **Authority / Status**: Public 심의필 정리본 (2025-10) / Product Data (행내한 2026.08)
- **Case Relevance**: 1992년생 → 60세 가정 2052 → 2050 또는 2055 빈티지가 산식상 후보이나, 은퇴 예상 시기 확인이 먼저이고 등급·성향 확인이 뒤따른다.
- **Limitation**: 특정 상품명 확정 금지; 라인업 수는 시점 의존.

### K-002. 같은 빈티지도 운용사별 위험자산 비중·위험등급이 다르다
- **Knowledge (Source-derived)**: 운용사·빈티지별 위험자산 비중표(16 시리즈): 2050 빈티지 약 67~80%, 2055 약 71~82%, 2020 빈티지도 27~37%. 추천펀드 자료의 TDF 위험등급 예(2030 빈티지 수익률 기준): KB온국민TDF 다소높은위험, 마이다스기본TDF 보통위험. 즉 "TDF"라는 유형만으로 등급이 정해지지 않으며 상품별 확인이 필요하다.
- **Source / Location**: SRC-094 L34–58 (매트릭스); SRC-095 L22–27
- **Authority / Status**: Product Data (행내한, 2026.08; 매트릭스 열 정렬 ⟨판독불확실⟩ 표시)
- **Case Relevance**: 위험중립형(4~6등급)이 매수 가능한 TDF는 상품별 등급 확인 대상; 높은 빈티지·적극 운용 시리즈는 3등급일 수 있음 → 빈티지 낮추기 또는 다른 유형.
- **Limitation**: 수치는 시점 의존·판독불확실 구간 있음.

### K-003. TDF·디폴트옵션 — 위임형 유형, 적격 TDF 100% 가능, 알파드림/뿔려드림 구성
- **Knowledge (Source-derived)**: TDF는 은퇴 시점에 맞춰 위험자산 비중을 자동 조정하고 분산투자·자동 리밸런싱을 제공하는 위임형 유형이며, 적격 TDF·디폴트옵션 상품은 적립금의 100%까지 운용 가능하다(주식형 펀드 70% 한도 예외). 디폴트옵션 포트폴리오: 알파드림2(저위험, 정기예금 50+TDF 50)·뿔려드림1(중위험, 정기예금 30+TDF 70) — 위험중립형은 뿔려드림까지 가입 가능. 최초 입금 후 2주 무지시 시 등록 DO 적용. TDF(집합투자증권)는 예금자보호 대상이 아니며 원금 손실 가능.
- **Source / Location**: SRC-090 L14–20, L60; SRC-003 L181; SRC-089 L35, L45–50; SRC-024 (TDF·DO 위임형 설명)
- **Authority / Status**: Public / Internal / Training
- **Case Relevance**: 원하는 등급의 TDF 직접 매수가 어렵거나 위임을 원하면 뿔려드림·알파드림 유형이 대안; 700만이 10주째 현금성인 이유(알파드림2 등록인데 미적용?) 확인.
- **Limitation**: 특정 상품·비중 금지.

### K-004. 연령·투자기간과 TDF — 나이만으로 단정하지 않는다
- **Knowledge (Source-derived)**: 30대는 은퇴까지 20년 이상이라 수익률을 추구할 시기이며 TDF가 적합한 유형으로 언급되지만, 선택은 자금 성격·투자기간·성향 순으로 확인한 뒤 한다. 나이만으로 판단하지 않는다.
- **Source / Location**: SRC-020 L24–30, L58–75; SRC-024 L21–51
- **Authority / Status**: Training
- **Case Relevance**: 34세·위험중립형 → TDF 유형 적합성은 인정하되 은퇴 시기·장기성 확인 선행.
- **Limitation**: —

### K-005. C1·C2·C3 — 위험중립형: 4~6등급, 뿔려드림까지
- **Knowledge (Human-approved)**: 위험중립형은 펀드 4~6등급(보통·낮은·매우낮은위험)만 권유 가능, 1~3등급(다소높은위험 포함) 불가. DO는 지켜드림·알파드림·뿔려드림. 성향은 상한.
- **Source / Location**: HD-2·2.1; SRC-096
- **Authority / Status**: Human-approved
- **Case Relevance**: "다소높은위험" TDF는 확정 추천 불가 → 등급 확인 절차 필요.
- **Limitation**: 부적합 상품을 고객이 원할 때의 절차는 Corpus에 없음.

### K-006. 채널 — 비대면 특정 펀드 지목 유의, 매수는 본인 앱(성향 확인)
- **Knowledge (Source-derived)**: 비대면 펀드 권유는 금소법 위반 소지가 있어 특정 펀드를 언급하지 않고 내점 제안·본인 선택으로 연결한다. 스타뱅킹 상품 검색에서 'TDF상품'·'추천상품' 테마로 찾을 수 있고, 매수 과정에서 투자성향 분석 결과가 확인된다. TDF 권유 시 "은퇴 예정 시기 질문으로 시작"하는 현장 정리가 있다.
