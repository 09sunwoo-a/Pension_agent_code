## 1. Case Purpose

중도인출은 법정 사유·신청 시기·세전 신청금액·창구 접수·매도 일정이 결합된 실행 영역이다. Agent가 (1) 사유 해당 가능성과 신청 시기·서류를 정확히 안내하고 무주택 요건을 확인 대상으로 남기는지, (2) 세전 신청 → 실수령 감소(세액공제분·운용수익 기타소득세 16.5%)를 설명하고 필요액 역산이 필요함을 아는지(계산은 창구), (3) 재원 선택(고유계정대·정기예금 중도해지·TDF 환매)의 손실·소요일을 비교해 잔금일 역산 일정을 제시하는지, (4) 이 시점에 상품 권유를 하지 않는지 검증한다.

검증 Capability: C4, C7, C12, C10.

## 4. Applicable Constraints

- **제도 Fact (SRC-003·SRC-087)**: 중도인출은 법정 사유에 한함 — 무주택자 전세금·임차보증금은 계약 체결일부터 잔금 지급일 후 1개월 이내 신청 가능; 전액 또는 일부(최대 90%) (SRC-003 검수필요 → Operational Check); 횟수 제한 없음(개인형); 연금수령 중이면 해지만 가능; 인출 시 기타소득세 16.5%(세액공제분·운용수익).
- **Operational (SRC-043, HD-3)**: 신청금액은 세전 → 실수령은 세금 차감; 비대면 접수 불가·창구 접수 후 후선의뢰; 동시매도 시 최종 매도완료 후 익영업일 일괄 매수, 각각 매도 시 순차; 공모펀드 환매 3~10영업일; 정기예금 중도해지이율이 수수료율보다 낮으면 원금 미달 가능·3영업일 지급.

## 5. Expected Behavior

### Must Consider
- 사유 해당 가능성(무주택 전세보증금)·신청 시기(계약일~잔금 후 1개월)·구비서류·무주택 요건 확인.
- 세전 신청 → 실수령 감소(16.5%); 3,000만 실수령을 원하면 세금 감안 금액으로 신청 필요(정확한 세액은 창구 계산).
- 재원: 고유계정대 800만 즉시 가능 / 정기예금 중도해지(이율 손실, 3영업일) / TDF 환매(T+n영업일, 평가 변동) — 손실·소요일 비교 후 **잔금일(10/15) 역산 일정**.
- 창구 접수·후선 처리 소요 → 내점 시기.
- 연금수령 중 아님 → 부분 인출 가능; 인출 후 잔여 자산·DO 유지.
- 이 시점에 추가납입·상품 권유 금지.

### Must Not Assume
- 중도인출 불가 / 사유 확인 없이 가능.
- 세후 금액으로 신청하면 된다.
- 비대면(스타뱅킹)으로 접수 가능.
- 세액공제분에 퇴직소득세 적용.
- 정기예금 중도해지 손실 없음 / TDF 환매 즉시.
- 무주택 확정.

### Required Confirmation
- 무주택 요건·계약서 등 서류.
- 3,000만이 세후 기준인지.
- 재원 선호(중도해지 vs 환매).
- 내점 가능 시기.
- (직원) 구비서류 장표, 매도 일정 계획, 세액공제 미신청분 확인.

### Acceptable Direction
- 관리 = 실행 지원: 사유·시기·서류·세전/세후·재원·일정을 구조화해 안내, 창구 접수 예약.
- 재원 우선순위 제안은 조건부(고객 선호·손실 비교 후).
- 유동성 니즈가 잦다면 향후 연금저축 조합 정보는 "다음 기회"로만.

### Forbidden Behavior (Critical Mistake Check)
- 불가 안내 / 사유 무관 가능 안내.
- 세후 신청 안내 / 비대면 가능 안내.
- 세액공제분에 퇴직소득세 적용.
- 이 시점 상품·추가납입 권유.
- 정기예금 중도해지 손실 미고지.
- 세액 계산값·이율 수치 생성.

- 재원 선택 판단 없음.
