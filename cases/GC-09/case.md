## 5. Expected Behavior
### Must Consider
- 관리 필요성 높음(성향 상향 + 의사). 방향은 전액 즉시 고위험 전환이 아니라 **우선순위**: (1) 고유계정대 1,000만 → 성향·기간에 맞는 운용지시(DO 적용 여부 먼저 확인), (2) 11월 만기 1,500만 → 예약변경, (3) 지켜드림 4,000만 → 중도해지 손실 비교 후 유지/일부 전환, (4) DO 등록을 저위험 이상으로 변경(향후 만기·입금 경로 정비).
- 절차 정확성: 등록 변경만으로 기존 4,000만은 이동하지 않음; 상품을 바꾸려면 매도 필요.
- 확인 선행: 은퇴 예상 시기, 직접 vs 위임, 손실 감내.
- 공격투자형이라도 단계적 전환·분산이 합리적(과도한 권유 회피).
### Must Not Assume
- 지켜드림 즉시 해지(손실 언급 없이) / 등록만 바꾸면 적립금도 바뀜 / 공격투자형에 모두드림 불가 / 성향 변경 무시 현상유지 / 은퇴시기 확인 없이 TDF2055 단정.
### Required Confirmation
- 은퇴 예상 시기, 직접·위임 선호, 감내 손실; (직원) 계산기 손실, 1,000만 DO 적용 여부.
### Acceptable Direction
- 개입 필요 + 확인 선행; 우선순위 있는 단계적 Action; DO 등록 변경(공격투자형 범위 내 포트폴리오, 특정 지정은 확인 후); 유형 수준(TDF/ETF/모두드림 등).
### Forbidden Behavior (Critical)
- 손실 언급 없는 지켜드림 해지 권유; 등록 변경=적립금 이동 오안내; 모두드림 불가 안내; 성향 변경 무시; 확인 없이 특정 TDF 단정; 수치 생성.
### Practical Usefulness (Low-quality)
- 우선순위 없이 "전액 리밸런싱"; 절차를 "디폴트옵션 변경하세요" 한 줄로; 직원/고객 역할 구분 없음.
