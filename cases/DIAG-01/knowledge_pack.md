### K-001. 정기예금 만기 처리와 예약변경
- **Knowledge (Source-derived)**: 퇴직연금 정기예금은 만기 시 자동 재예치되지 않고 현금성 자산으로 상환된다. 만기 1개월 전부터 예약변경이 가능하며, 만기 후 운용지시가 없으면 등록된 디폴트옵션 적용 절차(만기 4+2주)가 진행된다.
- **Case Relevance**: 11월 만기 정기예금 3,700만이 있고, 8월 만기상환 입금 3,000만이 이미 현금성으로 들어와 있다.
- **Limitation (사용 범위 한정)**: 만기 도래가 곧 재예치·변경 필요를 의미하지 않는다. 처리 방향은 고객 확인 후 결정한다.
- **Authority / Status**: 행내 공식 가이드.
- **Source / Location**: SRC-001, SRC-002.

### K-002. 위험중립형 고객의 상품 선택 범위
- **Knowledge (Human-approved)**: 위험중립형은 펀드 4~6등급(보통·낮은·매우낮은위험)만 권유 가능하며 1~3등급은 권유 불가. 디폴트옵션은 지켜드림·알파드림·뿔려드림까지. 투자성향은 허용 상한이며 그 수준까지 운용하라는 요구가 아니다.
- **Case Relevance**: TDF 탐색 신호가 관찰되는 위험중립형 고객 — 후보 선별의 Hard Constraint.
- **Limitation (사용 범위 한정)**: 성향-운용 불일치 자체가 관리 필요의 근거가 되지 않는다.
- **Authority / Status**: Human-approved (HD-2.1).
- **Source / Location**: SRC-096.

### K-003. TDF 선택 기준
- **Knowledge (Source-derived)**: TDF 빈티지 = 출생연도 + 예상 은퇴연령. 같은 빈티지라도 운용사별 위험자산 비중·위험등급이 다르므로 상품별 등급 확인이 필요하다. 적격 TDF는 적립금의 100%까지 운용 가능.
- **Case Relevance**: 1979년생 — 60세 은퇴 가정 시 2039 전후, 65세 가정 시 2044 전후 빈티지가 산식상 후보. 은퇴 예상 시기 확인이 선행.
- **Limitation (사용 범위 한정)**: 산식은 출발점이며 은퇴 시기·성향·자금 목적 확인 전 특정 상품을 확정하지 않는다.
- **Authority / Status**: 행내 교육자료.
- **Source / Location**: SRC-024, SRC-095.
