### K-001. 연금계좌 세액공제 구조 — 한도·구간별 공제율·결정세액 조건·확인 경로
- **Knowledge (Source-derived)**: 세액공제 한도는 연간 납입액 최대 900만원(연금저축 포함; 연간 납입한도 1,800만원과 구별). 공제율은 총급여 5,500만원 이하 16.5% / 초과 13.2%(지방소득세 포함). **세액공제 전 결정세액이 공제액보다 적으면 최대 환급액을 받지 못한다** — 실효 확인의 출발점은 원천징수영수증의 결정세액 항목이며, 납입한도 확인은 [06-12-151]·[04-10-099]에서 한다.
- **Case Relevance**: 총급여 2,600만원(16.5% 구간)·세액공제 잔여한도 700만원·"다 돌려받는 거죠?" 문의 — 잔여한도와 실제 환급이 다른 개념임이 이 상담의 핵심이다.
- **Limitation (사용 범위 한정)**: 결정세액 조건의 명시 근거는 공개 페이지 1건(행내 가이드는 권유 화법 방향으로만 서술) — 개별 고객의 실효 공제액·환급액 계산은 Agent Scope 밖(HD-1), 원천징수영수증·화면 확인으로 연결한다. 원천징수영수증 항목번호는 원천 간 불일치(SC-003) — 번호를 확정 인용하지 않는다. 잔여한도(700만원)를 그대로 납입 권유액으로 쓰지 않는다.
- **Authority / Status**: 행내 공식 가이드(T2) + 공개 페이지(결정세액 조건).
- **Source / Location**: OK-008 (SRC-003·087·008·025).

### K-002. 납입 후 중도인출·해지 시의 과세 구조 (장기 구속 고지)
- **Knowledge (Source-derived)**: 세액공제를 받은 가입자 부담금과 운용수익은 중도해지·일시금 수령 시 기타소득세 16.5%(지방소득세 포함)가 과세된다. 세액공제를 받지 않은 부담금은 과세제외다.
- **Case Relevance**: 추가 납입을 논의한다면, 납입 자금이 장기 구속을 수용할 수 있는 성격인지(중도 인출 시 과세 불이익)가 확인 대상이다.
- **Limitation (사용 범위 한정)**: 개별 추징·세액 계산은 Agent Scope 밖(HD-1). 과세기준은 세법개정에 따라 변동 가능.
- **Authority / Status**: 행내 공식 가이드(T2).
- **Source / Location**: OK-009 (SRC-003 L292~304).

### K-003. 안정추구형 고객의 상품 선택 범위
- **Knowledge (Human-approved)**: 안정추구형은 펀드 5~6등급만 권유 가능. 투자성향은 허용 상한이며 운용 요구가 아니다.
- **Case Relevance**: (납입 논의와 별개로) 상품 이야기가 나올 경우의 선별 기준.
- **Limitation (사용 범위 한정)**: 이 Case의 중심은 세액공제 확인이지 상품 권유가 아니다.
- **Authority / Status**: Human-approved (HD-2.1).
- **Source / Location**: OK-006 (SRC-096).
