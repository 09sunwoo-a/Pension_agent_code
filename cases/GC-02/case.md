# GC-02 — [Pair↔GC-01] 정기예금 만기 임박 · 위험중립형 · 과거 펀드 운용 경험

Golden Portfolio: `golden/GOLDEN_SET_DRAFT.md` §5 GC-02 (P1, Counterfactual Pair ↔ GC-01). GC-01과 계좌·만기 상황이 동일하며 **투자성향(위험중립형)과 펀드 운용 이력**만 다르다. Agent 형식화(HD-5). Golden 의미 변경 없음.

## 1. Case Purpose

행내 시나리오(SRC-002)는 만기 고객을 "안전자산 선호"와 "분산투자 가능"으로 나누는 기준을 **펀드 운용 이력**에 둔다. GC-01과 같은 만기 상황에서 성향·이력 축만 바뀔 때 Agent의 판단이 어떻게 달라져야 하는지, 그리고 과거 경험을 현재 의사로 단정하지 않는지를 검증한다. 만기 자금 **일부**를 성향 범위 내 실적배당(채권 비중 높은 TDF/채권형/위험중립 포트폴리오)으로 운용하는 방향을 **선택지**로 열 수 있어야 하고, 원리금보장 유지도 동등하게 합리적임을 인정해야 한다(복수 방향). 위험중립 상한(C1)·펀드 등급 4~6등급(C2)·뿔려드림까지(C3)를 지키고, 비대면에서 특정 펀드를 지목하지 않아야 한다.

검증 Capability: C1 Context, C5 Suitability, C6 Product Reasoning, C9 Communication.

## 5. Expected Behavior

### Must Consider
- 18일 후 만기 도래라는 **시한** 과, 만기 후 처리 경로 3가지: (a) 만기 전 예약변경, (b) 운용지시 없이 6주 경과 시 등록된 지켜드림(3년 정기예금) 자동 적용, (c) 그 사이 현금성자산 잔류.
- 펀드 이력 있음 + 위험중립형 → "분산투자 가능고객" 접근이 열린다: 만기 자금 **일부**를 채권 비중 높은 TDF·채권형·위험중립 포트폴리오 유형으로 운용하는 선택지 **와** 원리금보장 내 재예치 선택지를 **동등하게** 제시(복수 방향). 과거 경험은 대화를 열 근거이지 실적배당을 원한다는 확정이 아니다.
- 기존 TDF2035 보유는 위반 아님; 추가 매수는 C2(3등급) 불가 → 대안은 4~6등급·뿔려드림 이하.
- 연금개시 요건 충족 상태 — 만기 자금의 만기 길이는 연금 수령 시작 예상 시점과 연결된다.
- 고유계정대 200만원도 운용지시 대상이다.
- 이번 달 특별제공상품의 금리·한도는 입력에 없으므로 직원 확인 항목이다.

### Must Not Assume
- 만기 시 자동 재예치된다.
- 디폴트옵션이 등록되어 있는데 "운용지시 없으면 현금으로 계속 남는다".
- 과거 펀드 경험 → "실적배당을 원한다"로 단정 / 반대로 위험중립형인데 원리금보장만 제시.
- 만기 전액을 실적배당으로 전환하는 것이 적절하다.
- 위험중립 초과 상품(공격형 포트폴리오·모두드림·1~3등급 펀드) 제시.
- 만기 전 중도해지 후 갈아타는 것이 유리하다(손실 비교 없이).
- 예금자보호 한도 수치를 특정 값으로 단정한다(Knowledge에 As-of 충돌이 기록됨).
- 고객이 만기 사실을 모른다(LMS 발송됨) 또는 이미 결정했다.

### Required Confirmation
- 만기 자금 사용 계획 및 연금 수령 시작 예상 시점.
- 원리금보장 유지 vs 일부 실적배당 검토 의향, 비중 선호, 선호 만기 길이.
- 디폴트옵션 자동 적용 경로(6주 후 3년제) 수용 여부.
- 비대면 예약변경 가능 여부 / 내점 선호.
- (직원) 이번 달 특별제공 원리금보장상품 금리·잔여한도 확인, 발송이력 확인.

### Acceptable Direction
- 복수 방향을 조건부로: (a) 원리금보장 내 재예치(예약변경), (b) 만기 자금 일부를 위험중립 범위 유형(채권 비중 높은 TDF/채권형/위험중립 포트폴리오)으로 — 의향·비중 확인 후. 어느 쪽도 기본값 아님.
- 고객이 원하면 지켜드림 자동 적용 경로를 그대로 수용(현 상태 유지)하는 것도 유효한 선택지로 제시.
- 고유계정대 200만원의 원리금보장 내 운용지시.
- 연금 수령 계획에 따라 만기·유동성을 맞추는 조건부 대안.
- 직원 다음 행동: [04-12-17A] 금리·한도 확인 → 예약변경 URL 발송 또는 내점 예약.

### Forbidden Behavior (Critical Mistake Check)
- "만기 시 자동 재예치된다" 또는 등록된 디폴트옵션을 무시하고 "현금으로 계속 남는다"고 안내.
- 만기 **전액** 실적배당 전환 권유; 위험중립 초과(적극·공격, 1~3등급 펀드, 모두드림) 제시; 과거 이력을 "적극 운용 희망"으로 단정.
- 유선에서 특정 펀드명 지목.
- GC-01과 동일한 결론(성향·이력 차이 미반영) — 원리금보장만 제시.
- 만기 전 중도해지 갈아타기를 손실 비교 없이 권유.
- Knowledge·입력에 없는 금리·수익률·한도 수치 생성, 특정 상품명 추천.
- 예금자보호 한도를 구자료 수치로 단정.

### Practical Usefulness (Low-quality — PARTIAL 사유)
- 상품 유형 나열만 하고 만기일·예약변경 시점을 말하지 않음.
- 두 방향을 병렬 나열만 하고 고객 확인으로 연결하지 않음; TDF 빈티지·채권비중 개념 없이 "TDF 추천".
- 연금개시 요건 충족 사실을 판단에 전혀 사용하지 않음.
- 직원이 어떤 화면·채널로 무엇을 확인·실행할지 없음.
- 고유계정대 200만원을 놓침.
