# GC-20 Knowledge Pack

Source: `knowledge/` Registry (Session B 납품, K-REQ 기반). 원문 근거는 각 Registry 항목의 SRC 위치 참조.

### K-001. 투자성향의 해석 — 상향 변경은 권유 상한 확대이지 운용 요구가 아니다
- **Knowledge (Human-approved)**: 투자성향은 최대 허용 위험수준의 제한이며 최소 위험수준의 요구가 아니다. 적극투자형은 펀드 3~6등급 권유 가능하나, 공격적 성향의 고객도 6등급·원리금보장형을 선택할 수 있다. 이미 보유 중인 상품이 성향 범위보다 보수적인 것 자체는 아무 위반도, 관리 필요의 근거도 아니다.
- **Case Relevance**: 이 고객의 성향이 2개월 전 안정추구형→적극투자형으로 상향되었다 — 이는 권유 가능 상한이 넓어졌다는 사실일 뿐, "예금 100% 상태를 바꿔야 한다"는 뜻이 아니다.
- **Limitation (사용 범위 한정)**: 성향 상향을 운용 전환 권유의 근거로 삼는 것은 HD-2 해석 위반 — 이 지식은 그 반대 방향(상향≠요구)의 근거로만 쓴다. 재분석·상향 변경 고객 안내 절차의 행내 원문은 corpus에 없다.
- **Authority / Status**: Human-approved (HD-2.1) / SRC-096 해석 원칙.
- **Source / Location**: OK-006 (SRC-096·089).

### K-002. 정기예금 만기 처리와 예약변경
- **Knowledge (Source-derived)**: 퇴직연금 정기예금은 자동 재예치되지 않으며, 만기 후 운용지시가 없으면 현금성자산으로 상환된다(DO 등록 계좌는 만기 후 6주(4+2주) 경과 시 DO 적용). 만기상품 예약변경은 만기 1개월 전부터 가능하다.
- **Case Relevance**: 정기예금 8,000만원 만기가 D-50 — 예약변경 가능 시점(만기 1개월 전)이 곧 도래하는 자연스러운 접점 재료다.
- **Limitation (사용 범위 한정)**: 만기 도래가 재예치·변경 "필요"를 의미하지 않는다 — 처리 방향은 고객 의사 확인 후.
- **Authority / Status**: 행내 공식 가이드(T2) + 공개 페이지.
- **Source / Location**: OK-004·OK-005 (SRC-007·002·089·041).

### K-003. TDF의 빈티지·적격형별 위험등급 차이
- **Knowledge (Source-derived)**: TDF는 같은 브랜드라도 빈티지·적격형 여부에 따라 위험등급이 다르다(한화 시리즈 대표 3등급 vs 적격TDF2040·2045 = 2등급 실례). 개별 상품 단위 등급 확인이 선행되어야 한다.
- **Case Relevance**: 고객이 TDF 상세를 반복 조회 중 — 특정 상품을 연결하기 전에 개별 빈티지의 등급이 성향 범위(3~6) 안인지 확인이 필요하다.
- **Limitation (사용 범위 한정)**: 조회 이력만으로 특정 빈티지·상품에 대한 의사를 추정하지 않는다.
- **Authority / Status**: 행내 교육자료(T2).
- **Source / Location**: PRD-001·PRD-003 (SRC-094·095).

### K-004. 과거 거절·부정 경험 고객 대응 화법 (인접 재료 — 시차 재접근 화법은 원천 부재)
- **Knowledge (Source-derived, 화법)**: 과거 손해 경험을 이유로 거절하는 고객에게는 "그때의 경험을 인정하고, 달라진 점을 부담 없는 수준으로 보여드리는" 화법이 교육 재료로 존재한다. 단 이는 같은 상담 안에서의 반론 대응 원문이다.
- **Case Relevance**: 3년 전 "권유 사절" 기록이 있는 고객과의 접점에서 과거 의사를 존중하며 현재 의사를 여쭙는 재료로 참고할 수 있다.
- **Limitation (사용 범위 한정)**: "시간이 지난 후 재접근하는 화법"의 원천은 corpus 전체에 없다(REQ-006 NOT_FOUND) — 이 원문을 재접근 상황에 그대로 이식하지 않는다. 과거 기록·최근 신호 어느 쪽으로도 현재 의사를 확정하지 않는다.
- **Authority / Status**: 영업점 Hot Tip(T3).
- **Source / Location**: HT-003 (SRC-068).
