### K-001. 계약이전(전출) 접수 고객 처리 절차·원칙
- **Knowledge (Source-derived)**: 전출 접수 시 사전체크 — [06-AD-080] 전출조회로 이전 유형 확인(현금이전: 중도해지·환매 손실/불이익 확인이 필수 체크), [04-12-642]로 보유 상품 점검, 상품별 리스크(원리금보장형 중도해지 예상 손실·실적배당형 환매 소요기간)를 구체 수치로 사전 고지. 상담은 고객 의견 경청에서 시작하며, 고객이 이전을 진행하면 의사확인 절차가 안내되고 확인기한 내 미확인 시 자동 취소된다. 취소 의사 시 [06-AD-080] 전출취소(해제) 처리.
- **Case Relevance**: 2026-09-01 현금이전 방식 전출이 접수된 상태 — 현금이전은 보유상품 매도(정기예금 중도해지 포함)를 전제하므로 손익 영향 고지가 상담의 선행 요건이다.
- **Limitation (사용 범위 한정)**: 이 지식의 원천은 이탈 방어 가이드 — 은행의 이탈 방지 목적을 관리 필요성·추천 사유로 쓰지 않는다(HD-7). 고객 결정은 존중된다.
- **Authority / Status**: 행내 공식 가이드(T2).
- **Source / Location**: OK-002 (SRC-003 §03-2).

### K-002. 계약이전의 실물/현금 구조 — '일부 상품만 이전' 절차는 확인되지 않음
- **Knowledge (Source-derived, 부정 확인 포함)**: 확인되는 구조는 계좌 단위 이전이다. 실물이전에서는 이전 가능 상품은 그대로, 불가 상품(디폴트옵션 상품·상대기관 미취급 상품 등)만 현금화되어 이전되며, 신청 후 [06-AD-020]에서 가능/불가 상품을 확인한 뒤 고객이 **전체 이전의 수락/거절을 최종 결정**한다. **"계좌 내 일부 상품만 선택해 이전"하는 절차는 현재 확보된 원천 전체에서 확인되지 않는다 — 절차 서술도, 명시적 불가 서술도 없다.** 정기예금 중도해지이율의 구체 수치·산식도 원천에 없으며, [04-12-642] 연계 '정기예금 중도해지 예상조회'(만기전이율·중도해지이율·만기가치 vs 중도해지평가액 비교)로 조회한다.
- **Case Relevance**: CRM 취지상 고객 불만은 예금 금리에 국한되고 ETF는 유지 희망으로 보인다 — "예금만 옮기고 ETF는 둔다"는 경로의 실행 가능 여부가 이 상담의 핵심 미확인 사항이다.
- **Limitation (사용 범위 한정 — 중요)**: **부분 이전을 "가능"으로 가정하지도, "불가능"으로 확정하지도 않는다** — 현재 Knowledge로는 해당 실행경로를 확인할 수 없다는 상태를 유지하고, 실행 전 공식 확인(Operational Check)으로 연결한다 (HD-P2-GATE2 (1)). 중도해지이율 확정 계산은 Agent Scope 밖(HD-1) — 시스템 조회로 연결.
- **Authority / Status**: 행내 공식 가이드(T2) + 부정 확인(corpus 전수).
- **Source / Location**: OK-003 (SRC-010·003·065·067·027).

### K-003. 일반중도해지 vs 특별중도해지 — 이율 구조
- **Knowledge (Source-derived)**: 일반중도해지(개인 사정 임의해지)는 중도해지 패널티 이율(약정이율의 50~90% 수준)이 적용되고, 특별중도해지(법령이 정한 불가피한 사유 — 연금지급 등)는 약정이율 일할 계산으로 불이익이 없다.
- **Case Relevance**: 현금이전에 따른 정기예금 해지 시 적용 이율이 손익 고지의 핵심 변수다.
- **Limitation (사용 범위 한정)**: **계약이전(전출)에 따른 해지가 특별중도해지에 해당하는지는 원천에 서술이 없다 — 단정 금지, 확인 필요.** 개별 이율은 시스템 조회로만.
- **Authority / Status**: 행내 연수 교재(T2).
- **Source / Location**: OK-011 (SRC-097 L175~197).

### K-004. GIC(이율보증형보험)의 특성과 금리 비교 기준
- **Knowledge (Source-derived)**: GIC는 보험사 발행 원리금보장상품으로 예금자보호 대상이며, 별도 신청 없이 거래 가능하다. 금리 표시는 **공시이율(연복리)** — 정기예금(연단리)과 비교하려면 단리 환산이 필요하다(행내 단리 환산 계산기 존재). 금리·잔여한도는 월 단위로 변동한다.
- **Case Relevance**: 고객 불만이 예금 금리라면, 당행 안에서 확인 가능한 원리금보장 대안의 실제 조건(환산 기준 포함)을 보여주는 재료다.
- **Limitation (사용 범위 한정)**: 표기 금리의 단순 비교로 우열을 단정하지 않는다(복리/단리 기준 상이). 금리는 조회 시점 재확인 필요.
- **Authority / Status**: 행내 연수 교재(T2).
- **Source / Location**: OK-010 (SRC-097·001), PRD-018 (SRC-097).
