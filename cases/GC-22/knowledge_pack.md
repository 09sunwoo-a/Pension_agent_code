### K-001. 정기예금 만기 처리 — 자동 재예치 폐지·예약변경 1개월
- **Knowledge (Source-derived)**: 2023-07 근퇴법 개정 이후 정기예금 자동 재예치는 폐지되었고, 만기 후 운용지시가 없으면 만기자금은 현금성자산으로 상환된다. 만기상품 예약변경은 만기 1개월 전부터 가능 — 단말 [06-12-611] 또는 StarBanking 만기상품 예약변경 메뉴.
- **Case Relevance**: 정기예금 2,000만원의 만기가 **D-10** — 예약변경 가능 구간에 이미 들어와 있는, 시한이 가장 임박한 항목이다.
- **Limitation (사용 범위 한정)**: 만기 도래가 재예치·변경 필요를 확정하지 않는다 — 처리 방향은 고객 확인 후.
- **Authority / Status**: 행내 공식 가이드(T2) + 공개 페이지.
- **Source / Location**: OK-004 (SRC-007·002·089·041).

### K-002. 디폴트옵션 미등록 계좌의 만기 후 처리·등록 의무
- **Knowledge (Source-derived)**: DO 등록 계좌는 만기 후 6주(4+2주) 운용지시가 없으면 지정 DO가 적용되지만, **미등록 계좌는 별도 운용지시 전까지 만기자금이 현금성자산으로 계속 대기**한다. DO 지정은 DC·IRP 가입자의 법적 의무사항이다. 신규 입금분은 입금 후 2주 룰이 적용된다(등록 계좌 기준).
- **Case Relevance**: 이 계좌는 DO 미등록 + 퇴직급여 1.2억이 현금성으로 입금 5일째 + D-10 만기 예정 — 미등록 상태에서는 만기·입금 자금 모두 자동 운용 경로가 없다.
- **Limitation (사용 범위 한정)**: 6주 룰의 법령 원문·기산 방식은 corpus에 없음. "법적 의무"는 등록 안내의 근거이지 특정 DO 상품 권유의 근거가 아니다.
- **Authority / Status**: 공개 페이지(준법심의필) + 행내 가이드(T2).
- **Source / Location**: OK-005 (SRC-089·005·098).

### K-003. 퇴직급여 입금 직후 상담 순서 — 자금 계획 확인이 먼저
- **Knowledge (Source-derived, 화법·원칙)**: "먼저 자금 계획을 확인하고" 상담을 시작하는 것이 행내 가이드의 명시 원칙이며, 퇴직금 수령 고객 접점 화법도 사용 계획 질문으로 시작한다. 인출 구조(세액공제 미수령분→퇴직급여→공제분·수익 순) 점검이 이어진다.
- **Case Relevance**: 퇴직급여 1.2억이 입금 5일째 — 가장 큰 금액이지만, 운용 제안 전에 사용 계획(생활자금 필요 여부·연금 수령 계획)이 확인되어야 하는 대상이다.
- **Limitation (사용 범위 한정)**: 계획 미확인 상태에서 거액의 운용 방향·상품을 확정하지 않는다.
- **Authority / Status**: 행내 공식 가이드·연수 교재(T2).
- **Source / Location**: TALK-007 (SRC-003 L704~709), TALK-006 (SRC-011).

### K-004. ISA 만기자금의 연금계좌 전환입금 (60일·한도·추가 공제)
- **Knowledge (Source-derived)**: ISA 만기일로부터 60일 이내 만기자금의 전부/일부를 연금계좌로 추가 납입 가능(연간 납입한도 1,800만원과 별도), 전환금액의 10%·최대 300만원 추가 세액공제.
- **Case Relevance**: 타행 ISA 3,000만원 만기가 D-45 — 부 포인트 수준의 시한 항목.
- **Limitation (사용 범위 한정)**: 전환 의사 미확인 — 제도 시한 안내까지만. 실무 상세(횟수·증빙)는 T3 단독 근거.
- **Authority / Status**: 행내 공식 가이드(T2).
- **Source / Location**: OK-001 (SRC-003·072·087).

### K-005. 연금계좌 한도 3종·세액공제 구조의 구분
- **Knowledge (Source-derived)**: 연간 납입한도(1,800만원 합산)·세액공제 한도(900만원)·실효 공제(결정세액 조건)는 서로 다른 개념이다. 세액공제 잔여한도가 남아 있다는 사실만으로 납입 권유의 근거가 되지 않는다.
- **Case Relevance**: 입력의 세액공제 잔여한도 300만원·납입 가능 잔여한도 1,500만원은 서로 다른 값 — 혼용·상호 추정 금지(HD-8 6).
- **Limitation (사용 범위 한정)**: 개별 실효 공제·환급액은 Agent Scope 밖(HD-1).
- **Authority / Status**: 행내 공식 가이드(T2).
- **Source / Location**: OK-008 (SRC-003·087).
