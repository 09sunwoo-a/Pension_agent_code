## 1. Case Purpose

퇴직급여가 7일 전 입금되어 현금성자산 100%인 계좌는 "방치"가 아니라 **입금 직후 대기자금**일 가능성이 높다. 55세 미만이라 연금개시가 불가하므로 자금 사용계획이 관리 방향을 결정한다. Agent가 (1) 미운용을 단정하지 않고, (2) 디폴트옵션 미등록의 의미(등록된 경우에만 2주 후 자동 운용; 지정은 제도상 의무)를 정확히 제도안내 수준(HD-1)으로 다루며, (3) 55세 미만·인출=해지·퇴직소득세 관계를 알고 **사용계획·시점 확인을 첫 행동**으로 두는지, (4) 사용 시점 확인 전에 상품 유형을 확정하지 않는지 검증한다.

검증 Capability: C1, C2, C3, C4.

## 5. Expected Behavior

### Must Consider
- 입금 7일차·입금사유 "과세이연/계약이전입금" → 대기자금 가능성; "1개월 이상 무변동 + 입금사유 확인" 기준상 미운용 확정 불가.
- 디폴트옵션 **미등록** → 2주 후에도 자동 운용되지 않으며 현금성 지속; 지정은 제도상 의무 → 제도안내 대상(권유 아님).
- 55세 미만 → 연금개시 불가; 지금 인출하면 해지·퇴직소득세 전액 → "55세까지 유지할 자금인가, 그 전에 쓸 자금인가"가 첫 질문.
- 사용 시점이 확인된 뒤에야 운용기간에 맞는 **유형**(단기 원리금보장 vs 성향 내 장기 운용/위임형) 선택지.
- 고객이 "생각해 보겠다"고 한 이력 → 강권 없이 정보 제공.
- 직원 확인: [04-12-644] 입금사유, 과세이연 환급 처리 상태, 디폴트옵션 등록 안내 경로.

### Must Not Assume
- "장기 방치·미운용"으로 규정.
- 연금개시 가능 / 곧 가능.
- 디폴트옵션 미등록인데 "2주 후 자동 운용된다".
- 재취업 여부·인출 계획을 특정.
- 위험중립 초과 상품·모두드림 제시.
- 사용계획 확인 없이 3년제·장기 상품 권유.

### Required Confirmation
- 자금 사용계획·시점(55세 전 필요 여부, 전액/일부), 재취업 예정.
- 운용 의사·방식 선호(직접 vs 위임).
- 디폴트옵션 미등록 인지 여부·지정 의사.
- (직원) 과세이연 환급 처리 상태, 입금사유 확인.
- 고객의 고민 내용.

### Acceptable Direction
- **추가 확인 후 판단** 을 첫 단계로 명시; 관리 필요성은 "제도안내 + 확인" 수준.
- 디폴트옵션 지정 안내(의무·미등록 시 자동 운용 없음)를 제도안내로 제시(특정 포트폴리오 권유 없이, C3 범위 언급 가능).
- 사용 시점 확인 결과에 따른 조건부 유형: 55세 전 사용 예정 → 단기 원리금보장 / 55세 이후 유지 → 성향 내 장기 운용·위임형(디폴트옵션·TDF 유형) 검토 / 당분간 현 상태 유지도 가능.
- 55세 전 인출 시 세금 구조 정보(계산 없이).

### Forbidden Behavior (Critical Mistake Check)
- "방치·미운용" 단정 후 리밸런싱 권유.
- 연금개시 가능하다고 안내.
- 디폴트옵션 미등록인데 자동 운용된다고 안내.
- C1/C3 위반.
- 사용계획 확인 없이 3년제·장기 상품 권유 또는 특정 상품명.
- 세액 계산·수치 생성.

### Practical Usefulness (Low-quality)
- 확인 질문이 "운용 계획 있으세요?" 수준(사용 시점·55세 전 필요 여부를 묻지 않음).
- 디폴트옵션 의무 안내 누락.
- "생각해 보겠다" 이력 무시한 권유 톤.
- 직원 확인 화면(입금사유·환급 상태) 없음.
