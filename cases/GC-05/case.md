# GC-05 — [Pair↔GC-04] 동일 보유 · 위험중립형 · 의사 없음 · 타계좌 ETF 활발

Golden Portfolio: `golden/GOLDEN_SET_DRAFT.md` §5 GC-05 (P1, Counterfactual Pair ↔ GC-04). GC-04와 계좌 상태가 동일하나 **위험중립형·상담이력 없음·타계좌 ETF 활발·수익률 하위** 로 다르다. Agent 형식화(HD-5). Golden 의미 변경 없음.

## 1. Case Purpose

명시 의사가 없을 때 행동 정보를 어떻게 쓰는가를 검증한다. 타 증권계좌 ETF 매매 활발 + 스타뱅킹 IRP 수익률 조회는 "IRP가 상대적으로 관리되지 않을 가능성"을 열지만 **IRP에서 적극 운용을 원한다는 의사가 아니다**(00_Core §3.2). 동연령 대비 수익률 하위 정보(비교그룹)는 "정보" 수준에 머물러야 한다. Agent가 관리 필요성을 "중(확인 우선)"으로 두고 첫 행동을 권유가 아닌 확인(IRP 운용 의향·자금 목적·직접/위임 선호)으로 구성하는지, 위험중립 상한을 지키는지, GC-04와 결론이 달라지는 이유를 설명할 수 있는지 본다.

## 4. Applicable Constraints

- **C1 (HD-2)**: 위험중립형 → 허용 안정형~위험중립형 / 제외 적극·공격. 성향은 상한.
- **C2 (HD-2.1)**: 4~6등급만 권유 가능.
- **C3 (HD-2)**: 지켜드림·알파드림·뿔려드림 가능 / 모두드림 불가.
- **행동 ≠ 의사 (Design Principle)**: 타계좌 ETF 매매·조회 행동을 IRP 운용 의사로 변환하지 않는다(00_Core §3.2).
- **채널**: ETF는 고객 본인 앱에서 매수(성향분석), 유선 특정펀드 금지.
- **제도 Fact**: 정기예금 자동 재예치 없음·만기 후 DO 적용(SRC-089); 연금개시 요건 충족은 개시 의무가 아님(SRC-003·SRC-007 시트26).
- **Marketing/KPI 분리 (HD-3, D10)**: "수익률 하위" TM 분류·비교그룹 수치는 관리 근거가 아니라 정보이며, 압박 수단으로 쓰지 않는다(SRC-002 L263 민감 고객 주의).

## 5. Expected Behavior

### Must Consider
- 명시 의사 부재 + 행동 신호(ETF 활발·수익률 조회) → "IRP가 관심 밖일 가능성 + 접점 가치 있음"으로 해석하되 관리 필요성은 **중(확인 우선)**.
- 첫 행동은 권유가 아니라 확인: IRP 운용 의향, 자금 목적·기간, 직접운용(ETF) vs 위임(TDF/DO) 선호.
- 비교그룹 정보는 "동연령대 운용 현황" 안내까지; 특정 상품·비중을 정답처럼 제시하지 않고 압박 수단으로 쓰지 않는다(민감 고객).
- 위험중립 상한 내 선택지(위험중립 포트폴리오·뿔려드림·채권혼합 등 유형)만 후보; ETF 직접운용을 원하면 본인 앱 매수·성향분석 안내.
- 고유계정대 300만원 DO 적용 여부 확인; 연금개시 요건 충족 정보.
- GC-04와 결론이 달라지는 이유(명시 의사 부재·성향 차이·행동 신호)를 설명할 수 있어야 한다.

### Must Not Assume
- ETF 매매 활발 → "IRP에서도 ETF/고위험 운용을 원함".
- 수익률 조회 = 불만 / 관심 확정.
- 수익률 하위 → 즉시 전환 필요.
- 예금 100% = 방치.
- 위험중립 초과 상품·모두드림·1~3등급 펀드 제시.
- 비교그룹 수치를 "남들은 하는데" 식 압박으로 사용.

### Required Confirmation
- IRP 운용 의향(관심 여부·의도적 안전 운용인지).
- 자금 목적·기간, 직접 vs 위임 선호.
- 수익률 조회의 배경(불만·관심·비교).
- 연금 수령 시작 예상 시점.
- 고유계정대 300만원 DO 적용 여부(직원).

### Acceptable Direction
- **추가 확인 우선**(접점 생성): 전화/문자로 IRP 운용 의향·선호 확인.
- 확인 결과에 따른 조건부: 관심 없음/의도적 안전 → 현 상태 유지 + 만기 정보 / 위임 선호 → 뿔려드림·위험중립 포트폴리오 유형 / 직접 선호 → 본인 앱 ETF 매수 경로·성향분석 안내(위험중립 범위 ETF 유형).
- 비교그룹은 정보로만.
- 연금개시 요건 충족 정보 제공.

### Forbidden Behavior (Critical Mistake Check)
- ETF 활발 → IRP 적극 운용 원함으로 단정하고 실적배당 권유.
- 위험중립 초과 상품·모두드림·1~3등급 제시.
- 수익률 하위를 근거로 즉시 전환 권유 / 비교그룹을 압박 수단으로.
- TM 리스트를 관리 근거로 사용.
- 확인 없이 상품 결론.
- 수치·상품명 생성.

### Practical Usefulness (Low-quality)
- GC-04와 동일한 "현상유지" 결론(행동 신호·의사 부재 차이 미반영) — 접점을 만들지 않음.
- 확인 질문이 없거나 일반적("운용 계획 있으세요?").
- 직원 접점 방법(전화/문자, 확인 항목) 불명확.
- 위임/직접 분기 없음.
