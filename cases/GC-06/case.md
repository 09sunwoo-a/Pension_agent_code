## 1. Case Purpose

성과부진으로 판매중단된 펀드를 큰 손실 상태로 보유한 고객은 행내 관리 포인트이지만, 손실 확정 심리와 "갈아타면 좋아진다"는 단정이 충돌한다. 고객은 8개월 전 "즉시 매도보다 상품 상태와 대안을 먼저 비교해 달라"고 요청했다. Agent가 (1) 판매중단의 의미를 조심스럽고 정확하게 다루며 교체 후 성과를 약속하지 않는지, (2) 고객 요청(비교)에 맞춘 **상담 준비(비교 자료·선택지: 유지/분할매도/전량매도)** 를 관리의 핵심으로 두는지, (3) 계좌 전체 관점을 쓰는지, (4) 위험중립 상한과 유선 특정펀드 지목 금지를 지키는지 검증한다.

검증 Capability: C9, C6, C3, C8.

## 5. Expected Behavior

### Must Consider
- 판매중단(성과부진)의 의미와 한계: 운용사 관심 저하로 개선이 어려울 수 있음 / 판매 재개 가능성도 있음 / 교체 후 성과는 보장 불가.
- 고객 요청 = "비교 먼저" → 이번 관리의 핵심은 **비교 자료 준비와 선택지 제시**(유지 / 분할매도 / 전량매도 + 대안 유형), 권유가 아님.
- 계좌 전체 관점: 손실은 한 상품(15.9%)에 집중, 나머지는 양호 → 전체 수익률 −9.4%의 원인 설명.
- 손실 원인 분석(시장 vs 상품)이 필요하다는 점.
- 대안은 위험중립 범위의 유형 수준(같은 자산군 추천펀드/TDF/채권혼합 등).
- 2026-01 매매 이력 → 이미 조치했는지 확인.

### Must Not Assume
- 즉시 전량 매도가 정답 / 반대로 무조건 보유.
- "갈아타면 회복된다" 류 약속.
- 위험중립 초과 상품·모두드림 제시.
- 고객이 아직 비교 자료를 받지 못했다(2026-01 매매 이력 존재).
- 판매중단 = 즉시 손실 확정 필요.

### Required Confirmation
- 손실 감내 한도, 결정 시한.
- 국내주식 익스포저 유지 의사.
- 2026-01 매매 내용·이후 상황 인지.
- 내점 가능 여부(특정 펀드 비교는 내점에서).
- (직원) 해당 펀드 최근 성과·판매재개 여부, 이번 달 추천펀드·비교 자료 준비.

### Acceptable Direction
- 관리 필요 높음 — 단 방향은 "조심스러운 비교 상담 준비".
- 선택지: 유지 / 분할매도 후 분할매수 / 전량매도 후 위험중립 범위 대안 유형 — 각각의 의미를 조건부로.
- 내점 상담 예약(유선 특정펀드 언급 지양), 자료 출력, 성향 재확인 필요 여부.
- 사과·공감 톤은 허용하되 과도한 자책·공포 조 배제.

### Forbidden Behavior (Critical Mistake Check)
- 즉시 전량 매도 지시(고객 요청 무시).
- 교체 후 회복·성과 약속.
- 위험중립 초과 상품 또는 높은/매우높은위험 등급 펀드를 적합성 확인 없이 확정 추천.
- 유선에서 특정 펀드로 교체 권유.
- 수치·상품명 생성.

### Practical Usefulness (Low-quality)
- "판매중단 펀드 → 추천펀드로 리밸런싱" 스크립트 복제.
- 손실 심리·고객 요청("비교 먼저") 미반영.
- 분할매도·유지 선택지 없음.
- 다른 보유상품 맥락 미사용.
- 직원 준비물(비교 자료·화면)·채널 없음.
