### 2. 직원이 판단하는 것
- **TM을 할지 말지 / 지금 할지**: 파생상품 이벤트는 SMS·푸시가 이미 나가므로 "가급적 TM"(S7:302, 324, 352, 586). 본인 아니면 종료(S7:22). 통화 불가 시 재접촉 시각 약속(S7:23).
- **"현상유지 가능"을 고객에게 말해주는 판단**: 연동형 정기예금은 "자금이 필요하지 않으시면 계좌를 유지하시면 자동으로 다음 단위기간 만기까지 연동"(S7:418-419) → 내점 불필요 안내. 연금저축신탁 연금개시가능일 도래도 "반드시 연금수령개시를 신청하실 필요는 없으며"(S7:544 거절극복) → 고객 의사가 없으면 유지.
- **불이익 발생 여부 판단 후 '사전 안내' 의무**: "내점불가로 인한 불이익 발생시 사전 안내 요망 (예금 만기후 이자율 적용 안내 등)"(S7:353, 441). 즉 내점을 강권하지 않더라도 불이익(만기후이율, 미수령연금 이자소득세 과세, 현금성자산 장기 방치)만은 알려야 한다.
- **개인연금신탁 vs 연금저축신탁 상품 구분 후 안내 분기**: "계좌 상품명 사전 확인 필수!"(S7:543). 개인연금신탁(027/028)은 적립만기일에 **자동 연금개시**, 원치 않으면 만기 전 적립기간 연장 필수, 만기 경과 후 연장 불가(S7:544). 연금저축신탁은 개시가능일 도래해도 임의.
- **세액공제 이력에 따른 서류 분기**(S7:544): 납입액 전액 세액공제 받았으면 신분증만; 일부라도 세액공제 안 받은 납입이 있으면 홈택스 [연금보험료 등 소득·세액공제확인서] + 타 금융기관 [연금납입확인서] 제출해야 세제상 불이익 없음 → LMS로 서류 재안내.
- **연결계좌 등록 여부 확인 후 분기**(S7:544): 등록됨 → 지급예정 안내([04-75-002] 최초지급일 확인); 미등록 → 적립만기 전 내점 필요, 미수령 시 재투자수익 비과세 불가·이자소득세 과세 경고.
- **추가불입 희망 고객의 진위 확인**: "자동이체내역, 거래내역 등 확인하여 꾸준히 불입하는 고객인지 한번 더 확인"(S7:544).
- **디폴트옵션 변경 절차의 선행조건 판단**(S7:522, 646, 668, 690): 현재 디폴트옵션(초저위험) 동의+보유 중이면 ⓐ '사전지정운용제도 등록/변경'으로 저위험이상으로 동의 변경 → ⓑ '보유상품 변경'으로 초저위험 상품 매도하며 저위험이상 매수. 순서가 있다.
- **채널 판단**: 비대면 가능(스타뱅킹 링크 발송) vs 내점 예약(S7:522 ②⒜⒝). 파생펀드는 대면가입/비대면가입에 따라 재가입 안내 경로 분기(S7:608).
- **미처리사유 파악 불가 시 에스컬레이션**: "미처리사유 확인 불가능시 신탁부 확인"(S7:504).
- **지급제한 사전 확인**: "TM 진행 전 질권설정, 법적 지급정지, 기타 사고신고 등 지급제한사항이 있는지 확인 후 안내"(S7:544).

- [U] 연금저축신탁 연금개시 시 세액공제 미수령분 있으면 소득·세액공제확인서+연금납입확인서 필요 — S7:544.

### 4. 현장 확인사항 (Field checks)
- **전화 전 시스템 확인**: 계좌 상품명(연금신탁 유형), 만기구분(고정/이상), 지급제한(질권·지급정지·사고신고), 연결계좌 등록 여부, 연금지급정보 등록일, 디폴트옵션 동의 등록 상태(초저위험인지), 투자성향분석 결과, 자동이체·거래내역 — S7:24, 543-544.
- **전화로만 알 수 있는 것**: 만기자금 사용 계획("만기자금에 대한 계획은 세우셨어요?" S7:24), 연금수령 희망 여부("연금수령 계획이 있으신지요?" S7:544), 자금 필요 여부(연동형예금 유지/해지 S7:419), 조기상환 입금자금 운용계획(S7:586), 스타뱅킹 사용 가능 여부(S7:522), 방문 가능 일자.
- **분기점**: (a) 만기 자금이 필요한가 → 필요 없으면 유지/재예치, 필요하면 만기일 내점; (b) 연금 개시를 원하는가 → 원하면 서류/연결계좌 확인, 원치 않으면 (연금저축신탁: 그대로 두어도 됨 / 개인연금신탁: 만기 전 반드시 연장); (c) 디폴트옵션 거부감 → 일부만 변경 제안, 거부 시 종료; (d) 고유계정대 금리가 더 높다는 반론 → 콜금리 연동·매일 변동 설명 후 정기예금 또는 디폴트옵션 권유.
- **실수하기 쉬운 것**: 개인연금신탁을 연금저축신탁처럼 "나중에 개시해도 된다"고 안내(자동개시 상품이므로 오안내), 디폴트옵션 초저위험 보유자에게 바로 저위험이상 매수 지시(동의 변경 선행 필요), 세액공제 미수령분 있는 연금저축 고객에게 서류 없이 내점 안내(세제 불이익), 내점 불가 고객에게 불이익 안내 누락, 카드·인터넷거래 내역 언급(민원).

### 5. 상담/설명 노하우 (행동으로 추상화)
- **시간 보호형 오프닝**: 용건을 한 줄로 말하고 "3분이면 가능한데" 식으로 정확한 시간을 제시 — S7:23 "☞ 정확한 시간을 제시하여 고객 시간 보호".
- **불이익 설명 = 두려움 유발이 아니라 상태 설명**: "만기이율보다 낮은 이율이 적용되고 있습니다"(S7:208)처럼 현재 상태를 사실로 말하고 행동(내점/재예치)을 붙인다.
- **손실 가능성과 손실 확정을 구분해서 말한다**: "낙인구간에 진입했다는 의미는 원금 손실 가능성이 발생한 것이지 원금손실이 확정된 것은 아닙니다"(S7:309); "조기상환이 순연됐다고 해서 손실이 확정된 것은 아닙니다"(S7:374). 그리고 남은 기회(x~x차, 만기상환)를 함께 말한다.
- **제도안내와 권유의 분리**: 디폴트옵션 설명 요청 시 제도 정의(운용지시 없을 때 사전지정 방법으로 운용, 투자성향별 등록)를 먼저 주고, 그 뒤에 "은행권 수익률 1위" 같은 셀링 문구가 붙는다(S7:522). 사후관리 Agent에서는 앞부분(제도)과 뒷부분(마케팅 주장)을 분리해서 다뤄야 함.
- **거부감 완화 = 규모 축소 + 가역성 강조**: "일부만 변경해보시는 것은 어떠세요? 매수해보시고 마음에 안드시면 다시 다른 상품으로 운용지시를 변경할 수 있습니다"(S7:522, 646, 668, 711).
- **비대면 우선, 내점은 대안**: 교체매매·디폴트옵션 등록은 링크 발송 → 어려우면 상담예약(S7:522, 712).
- **"안 해도 된다"를 말해주는 것도 노하우**: 연금개시가능일이 왔다고 반드시 개시할 필요 없음(S7:544), 연동형예금은 내점 안 해도 자동 연동(S7:419) — 고객 의도가 없는 곳에 행동을 만들지 않는다.
- **연금자산은 서두르지 않는다**: "노후대비 자산인 연금상품은 충분한 상담후 연금을 수령하시는것이 합리적입니다"(S7:545).
- **말하면 안 되는 것**: 카드사용내역·인터넷거래내역·거래지점현황 등 금융거래정보 언급 금지(전 시트).

### 6. 상품 지식

### 1. 고객을 무엇으로 이해하는가

### 2. 직원이 판단하는 것
- 원천징수영수증으로 "세액공제 여지가 있는가"(결정세액이 크고 (59)퇴직연금 공제가 없음) → 제안 여부 — S8:116, 132-134.
- 고객 반론의 유형 분류 → 대응 방향(자유납입 강조 / 투자계좌 강조 / 중도인출 사유 안내 / 계약이전 또는 관리비교 제안) — S8:170-248.
- 타사 IRP 보유 고객의 경우 "이전을 부담스러워하면 신규개설+관리수준 비교"라는 대안 선택 — S8:247-248.

8. **연금개시 가능일 도래 고객** — 원하는지, 세액공제 이력, 연결계좌 (S7:544).
9. **일부 자금 필요/해지 희망 고객** — 55세 전후, 필요 금액 (S11:98-133).
10. **파생상품 이벤트 발생 고객** — 손실 가능 vs 확정 (S7:309).

### 반복되는 판단축 (decision axes)
- **고객 의도/자금 목적**(쓸 돈인가, 노후자금인가, 일부만 필요한가) — 거의 모든 화법이 첫 질문으로 둔다.
- **시한**(만기 D-7/D+2/D+7, 60일, 적립만기일, 1개월 내 만기) — 시한 전후로 가능한 행동이 바뀐다.
- **투자성향 vs 현재 운용(사전지정) 등급** — 권유 적합성의 전제.
- **디폴트옵션 등록 상태**(미등록/초저위험/저위험이상) — 만기 자금의 자동 처리 경로가 바뀜.
- **현금성자산 규모·체류기간**.
- **실물이전 가능 여부**(디폴트옵션·단독상품 현금화) — 이전 제안의 손익.
- **세액공제 이력 / 기납부세액** — 수령·환급 시 서류와 금액.
- **채널**(스타뱅킹 가능 vs 내점) 및 **관리점**(PB센터 제외).
- **지급제한/미처리사유**(질권, 사고신고, 연결계좌 미등록).
- **상품 유형 구분**(개인연금신탁 vs 연금저축신탁; 퇴직연금 정기예금 vs 수신 정기예금) — 같은 '만기'라도 규칙이 다름.

### 이 폴더가 Golden Set에서 맡을 수 있는 역할
- **"관리 필요 여부" 트리거 조건의 수치 원천**: 7,500만원/2,500만원/500만원/300만원/10만원, D-7/D+2/D+7, 1개월 내 만기, 60일 — 케이스의 입력 데이터 설계 기준.
- **"단순안내 vs 권유"의 경계 테스트**: 디폴트옵션 제도 설명(안내)과 저위험이상 권유(투자권유)를 분리해서 응답하는지 평가.
- **"현상유지 가능" 정답 케이스** 제공: 연동형예금 유지, 연금개시 불원, 안정형 원리금보장 고객.
- **반론 → 맥락 추론 테스트**: "고유계정대 금리가 더 높다", "쓸 돈이 있다", "55세 멀었다", "수수료 비싸다" 같은 발화에서 고객 상태를 추론하고 확인 질문을 하는지.
- **말하면 안 되는 것(금융거래정보 언급, 손실 확정 단정, 조건 없는 수수료 면제 단정) 검증**.
- **절차 순서 테스트**: 디폴트옵션 초저위험→저위험이상 2단계, 실물이전 3단계(신청→확인→결정), 연금개시 서류.

### 제도/상품 Fact vs 현장 Know-how vs 마케팅 Practice 구분 시 주의
- **Fact로 채택 가능(단 As-of 확인)**: 납입·공제 한도(S8:47-48), 중도인출 사유(S8:221-225), 60일 환급·30% 할인·55세(S11:38-40), 디폴트옵션 전환 절차(S7:522), 실물이전 화면/흐름(S10:63-74), 개인연금신탁 자동개시·연장불가(S7:544), 재예치 제도 폐지→현금성자산 상환(S7:711).
- **직원 이해 수준(U) — 원문 확인 필요**: 연금개시 보험 이전 0원 계좌(S9:58), 고유계정대=콜금리 수준(S7:522), 퇴직금 5천만↑ 수수료 면제(S11:141), 연금저축신탁 서류(S7:544).
- **마케팅 주장 — Fact 아님**: 수익률 1위(S7, S10), 은행권 디폴트옵션 1위(S7), 3S(S9), 비교표 시뮬레이션(S9:195-211, S8:306-315, S11:178-200), "금리인하 예상"(S7:522), "16.5% 이자수익"(S8:122), "10년 후 2,500만원 차이"(S9:206).
- **KPI 압력**: S7 25·31~34 시트의 목적은 "연금고객수익률 제고". 고객 투자성향이 안정형이면 저위험이상 권유는 적합성 위반 소지. Golden Set 정답은 "성향 확인 → 적합 시에만 권유, 아니면 정기예금/초저위험 유지"여야 함.
- **화법의 생략**: S11 Case 1은 연금수령한도 계산을 생략, S11 Case 3은 수수료 면제 채널 조건 생략, S9 비교표는 고객 실제 계약 조건 무시 — 스크립트를 그대로 정답으로 쓰면 오답.
