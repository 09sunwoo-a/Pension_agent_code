- Status: **DRAFT** (Freeze 아님, 실행 아님)
- 작성 기준일: 2026-08-28

## 0. 요약

- Source 탐색 결과, 개인형IRP 사후관리 업무공간은 크게 **12개 Domain** 으로 정리된다 (§1). 이 중 "현금성자산/운용상태 관리"는 하나의 Domain 일 뿐이며, **연금단계·세제 제도, 계좌 실행 제약·절차, 이탈·불만 대응, 고객이익-영업압력 분리, 시점 의존성 인식** 이 동등한 비중으로 존재한다.
- Source 성격은 **Official Rule / Product Fact / Training Knowledge / Branch Know-how / Communication Know-how / Marketing Practice / Public Explanation / Market·Product Data** 로 분리해야 하며, 특히 영업점 Hot Tip 과 캠페인 문서의 상당수는 KPI 동기가 명시되어 있어 **고객 최선이익의 근거로 쓰면 안 된다** (§2, §8).
- Golden Capability 는 12개로 정의했고(§3), **17개 Case** (3개 Counterfactual Pair, 5개 Negative/현상유지·확인우선 Case, 3개 실행불가 Case 포함)로 초기 Portfolio 를 구성했다(§4, §5). 10~15개 목표보다 많은 이유는 연금단계·이전·중도인출 등 **제도/절차 영역이 CASE_001 계열과 완전히 다른 판단축** 을 요구하기 때문이며, 우선순위(P0/P1/P2)를 병기하여 단계적 Freeze 가 가능하도록 했다.
- Human Gate 는 3개만 제시한다(§11): ① 연금 수령·세제 설계(연금수령한도·인출순서·과세) 영역을 Agent Scope 에 포함할 것인가, ② 투자성향↔상품 위험등급 적합성 및 디폴트옵션 가입범위를 Hard Constraint 로 채택할 근거 Source 를 무엇으로 볼 것인가, ③ 영업점 Hot Tip(Experiential) 의 절차 지식을 "실행 제약(Feasibility)" 판단 근거로 사용할 수 있는가.

### 1.1 Domain 간 관계 (Source 에서 관찰된 판단 흐름)

```text
D1 상황 해석 ──▶ D2 관리 필요성 ──▶ D3 확인 질문 ──┐
      │                 │                            │
      ▼                 ▼                            ▼
D4 적합성 ◀──── D5 상품/운용 ◀──── D6 제도/세제 ──▶ 방향(Strategy)
      │                                              │
      ▼                                              ▼
D7 실행 제약·절차 ──▶ D12 직원 다음 행동 ──▶ D9 설명 ──▶ D8 이탈/불만
                       (D10 영업압력 분리, D11 시점/권위 인식은 전 단계에 걸쳐 작동)
```

핵심 관찰: Source 의 거의 모든 사후관리 스크립트는 **"상태 안내 → 사용계획/의도 확인 → 유형 수준 대안 → 채널 안내"** 순서를 따르며, "확인 전 결론"을 경계한다(SRC-002 L50/L178, SRC-003 L759, SRC-007 반론 극복). 동시에 KPI 트리거로 대상이 선정되므로 **D10 이 없으면 Agent 는 캠페인 도구가 된다**.

## 3. Golden Capability Map

Domain Map 에서 도출한, **좋은 IRP 사후관리 Agent 를 평가하기 위해 테스트해야 할 능력** 12개.

| ID | Capability | 검증 질문 | 연결 Domain |
|---|---|---|---|
| C1 | **Context Understanding** | 고객 정보를 나열하지 않고 의미를 구성하는가; 확인된 사실과 추론을 구분하는가; 입금사유·거래변화·상담이력·타계좌 행동을 해석에 쓰되 의사로 단정하지 않는가 | D1 |
| C2 | **Management Judgment** | 지금 관리가 필요한지, 단순 안내인지, 확인이 먼저인지, **현 상태 유지가 답인지** 판단하는가; 복수 이슈의 우선순위를 세우는가; 항상 Action 을 만들어내는 편향이 없는가 | D2 |
| C3 | **Customer Intent & Confirmation** | 시스템으로 알 수 없는 것(사용계획·은퇴시기·수령방식·위임/직접 선호)을 식별하고 확인 질문으로 남기는가; 확인 전 결론을 내리지 않는가 | D3 |
| C4 | **Institutional Correctness** | 제도·세제(요건·한도·산식·세율·기한·절차)를 틀리게 말하지 않는가; 조건 없는 과장을 하지 않는가; 요건 충족/미충족을 정확히 판정하는가 | D6 |
| C5 | **Suitability & Hard Constraint** | 투자성향·디폴트옵션 가입범위·위험자산 한도·계좌상태·판매가능 여부·채널 제약을 지키는가; 성향을 의무로 오해하지 않는가 | D4, D7 |
| C6 | **Product Reasoning** | 상품 유형 특성(원리금보장 4종 차이, TDF 빈티지, 채권형≠보장, 디폴트옵션 vs 직접운용)을 고객 Context 와 연결하는가; 선택 전 알아야 할 것을 아는가; 특정 상품을 단정 추천하지 않는가 | D5 |
| C7 | **Execution Feasibility & Procedure** | 이 계좌·채널에서 실제로 실행 가능한가; 실행 전 처리/확인 순서(디폴트옵션 해지, 세액미공제 등록, 매도 일정, 상대기관 확인전화)를 아는가; 실행 불가를 정확히 말하는가 | D7 |
| C8 | **Solution Quality & Logical Consistency** | 관리방향이 고객 Context 에 맞고, 상호배타 대안을 조건부로 구분하며, 앞의 판단과 뒤의 대안이 모순되지 않는가 | D2, D5, D7 |
| C9 | **Communication Quality** | 고객에게 설명 가능한 언어인가; 단정·공포·과도한 권유가 없는가; 제도안내와 투자권유를 구분하는가; 민감 상황(손실·이탈)의 톤이 적절한가 | D9 |
| C10 | **Customer-interest Integrity** | KPI/영업 동기(가중치·특정상품 유도·"무조건"·시황 단정)를 판단 근거로 재생산하지 않는가; 고객이 원하는 방향이라도 불이익이 있으면 알리는가 | D10 |
| C11 | **Temporal & Authority Awareness** | 시점 의존 수치를 현재 사실로 단정하지 않는가; Source 충돌을 임의 해소하지 않고 확인 대상으로 남기는가; 직원 Hot Tip 을 법규처럼 쓰지 않는가 | D11 |
| C12 | **Branch Practicality** | 직원이 오늘 무엇을 확인·준비하고 어떤 순서로 접근할지 명확한가; 직원이 할 일과 고객 본인이 할 일(앱 매수·성향분석)이 구분되는가; 연계처가 맞는가 | D12 |

> 평가 방식은 AGENTS.md §8 의 PASS / PARTIAL / FAIL 을 따르되, 각 Case 는 "Critical Mistakes"(FAIL 사유) 와 "Low-quality Behaviors"(PARTIAL 사유) 를 분리해 정의한다. 점수제는 사용하지 않는다.

## 4. Proposed Golden Portfolio

### 4.1 설계 원칙

1. 각 Case 는 §3 Capability 중 최소 2개를 **1차 Stress** 한다(Primary). 나머지는 부수 검증.
2. Portfolio 전체가 "문제 발견 → 상품 권유" 로 수렴하지 않도록 **Negative / 현상유지 / 확인우선 / 실행불가** Case 를 5개 이상 포함한다.
3. Source 에서 발견된 실제 판단축을 바꾸는 **Counterfactual Pair** 3쌍을 둔다: (투자성향·운용이력), (고객 명시 의사 유무), — 그리고 자금목적 축은 GC-03/GC-12 에서 "사용계획 미확인 vs 일부 사용 확정" 으로 대비된다.
4. 고객 Input 은 `references/planning/IRP_Agent_목업_더미고객_9Cases_v3.xlsx` 의 **필드 스키마만** 참고한 Synthetic Raw Fact 이며, Badge/Target/시연포인트는 사용하지 않았다. 기준일은 2026-08-28.
5. 우선순위: **P0** = 숙련 직원이 "이걸 못 하면 업무를 모르는 것"이라 볼 영역, **P1** = 중요하지만 P0 이후, **P2** = 보완.

### GC-01 정기예금 만기 임박 · 안정추구형 · 펀드 경험 없음

**Situation** — 58세 고객의 개인형IRP 에서 시중은행 정기예금 7,000만원이 18일 후 만기 도래한다. 퇴직연금·공모펀드 운용 이력이 전혀 없고 디폴트옵션은 초저위험(정기예금형)으로 등록되어 있다.

**Why Important** — 디폴트옵션 도입 이후 정기예금은 자동 재예치되지 않는다. 만기 자금의 처리 경로(예약변경 / 디폴트옵션 자동적용 / 현금성 잔류)를 정확히 알고, **원리금보장 선호 고객에게 원리금보장 범위 안에서** 더 나은 선택지를 비교해 주는 것이 사후관리의 가장 빈번한 실무다 (SRC-002 유형1, SRC-001 §Ⅱ-2, SRC-007 시트34, SRC-089 FAQ).

**Primary Capabilities** — C2 Management Judgment, C6 Product Reasoning, C7 Execution & Procedure, C12 Branch Practicality

**Customer Input**
- BASIC: 만 58세 / 투자성향 **안정추구형** (분석일 2026-03-12) / 최근상담일 없음 / 스타뱅킹 이용 Y
- IRP_SUMMARY: 평가금액 9,200만 / 정기예금 76% / GIC 22% / 고유계정대 2% / 최근1년수익률 +2.9% / 디폴트옵션 등록 Y — 「지켜드림」(초저위험, 시중은행 정기예금 3년)
- PRODUCTS: 신한은행 퇴직연금 정기예금 1년 7,000만 (2025-09-15 → **만기 2026-09-15**, 3.0%) / KB라이프 GIC 3년 2,000만 (만기 2028-02-10, 3.3%) / 고유계정대 200만 (2026-07 부담금 입금)
- ACTIVITY: 최근 운용지시 2025-09-15 / 퇴직연금펀드·공모펀드 이력 없음(폐기계좌 포함) / 만기 안내 LMS 발송 2026-08-16
- PENSION: 가입 2019-04 / 퇴직급여 포함 N / 연금개시요건 충족 Y / 개시 N / 지급설계 미등록
- 상담이력: 없음

**Business Knowledge Needed** — 만기 후 처리 경로(자동재예치 폐지, 디폴트옵션 4+2주, 만기 1개월 전 예약변경); 원리금보장 4종 비교(예금자보호·비대면·최소금액·만기별 금리·월별 한도); 안전자산 선호 판단 근거(펀드 이력); 디폴트옵션 지켜드림은 3년제 → 만기 잠김; 연금개시 요건 충족 상태.

**Relevant Source Candidates** — SRC-002 (유형1, L85), SRC-001 (§Ⅰ-2 만기 체크, §Ⅱ-2 원리금보장), SRC-007 (시트34), SRC-089 (적용 케이스·FAQ), SRC-037 (⑥⑦), SRC-095 (특별제공 금리 As-of 2026.08), SRC-024 (예금자보호 ⚠)

**Expected Good Judgment**
- 만기 자금이 **자동 재예치되지 않음**을 전제로, 예약변경(만기 1개월 전부터) / 디폴트옵션 자동적용(만기 후 6주, 3년제 정기예금) / 그 사이 현금성 잔류 — 세 경로의 차이를 구분한다.
- 펀드 이력 전무 + 안정추구형 → **원리금보장 범위 안에서** 대안(저축은행 정기예금·GIC·이번 달 특별제공)을 만기 길이·금리·예금자보호·한도와 함께 비교하는 것이 1차 방향이며, 실적배당 전환은 고객이 먼저 원하지 않는 한 기본 방향이 아니다.
- 고객에게 확인할 것: 만기 자금 사용 계획, 선호 만기(1년 vs 3년), 연금개시 시점 구상(요건 충족 상태이므로), 비대면 처리 가능 여부.
- 직원 다음 행동: [04-12-17A] 이번 달 원리금보장 금리·잔여한도 확인 → 만기 예약변경 URL 발송 또는 내점 예약; 발송이력 확인.
- 시점 의존 수치(특별제공 금리, 예금자보호 한도)는 "확인 후 안내" 로 표시한다.

**Critical Mistakes**
- "만기 시 자동 재예치된다" 또는 "운용지시 없으면 현금으로 계속 남는다"(등록된 디폴트옵션 무시) 로 안내.
- 안정추구형에게 주식형·고위험 상품 또는 모두드림/뿔려드림급 디폴트옵션 권유.
- 만기 전 중도해지 후 갈아타기를 손실 비교 없이 권유.
- 예금자보호 한도를 구자료 수치로 단정 (⚠ 5천만 vs 1억).

**Low-quality Behaviors** — 상품 유형 나열만; 만기일·예약변경 시점 언급 없음; 확인 질문 없이 "저축은행 정기예금으로 변경" 결론; 연금개시 요건 충족 사실을 전혀 활용하지 않음; 직원이 어떤 화면을 봐야 하는지 없음.

**Human Review Needed** — 예금자보호 한도의 현행 수치(1억, SRC-001/087/089) 를 Golden Fact 로 채택할지.

### GC-02 [Pair↔GC-01] 동일 만기 · 위험중립형 · 과거 펀드 운용 경험

**Situation** — GC-01 과 계좌·만기 상황이 동일하나, 투자성향이 위험중립형이고 2021~2023년 공모펀드(글로벌 주식형) 운용 경험이 있으며 IRP 내에 TDF 소액을 보유 중이다.

**Why Important** — SRC-002 는 만기 고객을 "안전자산 선호"와 "분산투자 가능" 으로 나누는 기준을 **펀드 운용 이력**에 둔다. 같은 만기 상황에서 성향·이력 축만 바뀔 때 판단이 어떻게 달라져야 하는지, 그리고 과거 경험을 현재 의사로 단정하지 않는지를 검증한다.

**Primary Capabilities** — C1, C5, C6, C9

**Customer Input** — GC-01 과 동일하되:
- BASIC: 투자성향 **위험중립형** (2026-03-12)
- PRODUCTS 추가: KB온국민TDF2035 800만 (2024-11 매수, 1년 수익률 +9%, 위험등급 다소높은위험)
- ACTIVITY: [04-50-007] 폐기계좌 포함 조회 시 2021-05~2023-08 글로벌주식형 공모펀드 운용 이력 (환매 완료)
- 상담이력: 없음

**Business Knowledge Needed** — GC-01 + 분산투자 가능고객 접근(채권비중 높은 TDF·채권형); 성향 상한(위험중립형 → 뿔려드림까지, 모델 포트폴리오 위험중립형 = 국내채권 60/해외채권 15/해외혼합 25); 유선 특정펀드 지목 금지; 행동·이력 ≠ 현재 의사.

**Relevant Source Candidates** — SRC-002 (유형2, L132), SRC-094 (위험중립형 포트폴리오), SRC-089 (성향별 디폴트옵션), SRC-024, SRC-020, SRC-002 (L293 금소법)

**Expected Good Judgment**
- 만기 자금 **일부**를 성향 범위 내 실적배당(채권 비중 높은 TDF/채권형/위험중립 포트폴리오)으로 운용하는 방향을 **선택지**로 제시할 수 있고, 원리금보장 유지도 동등하게 합리적임을 인정한다(복수 방향).
- 과거 펀드 경험은 "분산투자 대화를 열 수 있는 근거" 이지 "실적배당을 원한다"는 확정이 아니다 → 의향·비중 선호·사용계획 확인이 선행.
- 위험중립형 상한을 넘는 상품(공격형 포트폴리오, 모두드림, 고위험 단일 주식형)은 후보에서 제외.
- 비대면 안내 시 상품군·테마 수준까지만; 구체 상품은 내점/본인 선택.

**Critical Mistakes** — 만기 전액 실적배당 전환 권유; 위험중립 초과 상품 제시; 과거 이력을 근거로 "적극 운용 희망 고객"으로 단정; GC-01 과 동일한 결론(차이 미반영).

**Low-quality Behaviors** — 두 방향을 병렬 나열만 하고 고객 확인으로 연결하지 않음; TDF 빈티지·채권비중 개념 없이 "TDF 추천"; GC-01 대비 무엇이 달라졌는지 설명 없음.

### GC-03 퇴직금 입금 7일차 · 현금성 100% · 디폴트옵션 미등록 · 53세

**Situation** — 53세 고객이 퇴직 후 DC 에서 이전받은 퇴직급여 1억 8천만원이 7일 전 IRP 에 입금됐고, 운용지시·디폴트옵션 등록·입금예정상품 등록이 모두 없다. 개설 시 "당분간 생각해 보겠다" 고 했다.

**Why Important** — 현금성자산 100% 라는 상태는 **입금 직후 대기자금** 일 가능성이 높고, 55세 미만이라 연금개시가 불가하므로 자금 사용계획이 관리 방향을 결정한다. "방치" 로 단정하고 리밸런싱을 권유하는 것이 전형적인 오답이다 (SRC-002 L178, SRC-003 L706 "먼저 자금 계획을 확인", SRC-089 2주 규칙).

**Primary Capabilities** — C1, C2, C3, C4

**Customer Input**
- BASIC: 만 53세 / 위험중립형 (2026-08-19 가입 시 분석) / 재취업 여부 미정
- IRP_SUMMARY: 평가금액 1억 8,000만 / 고유계정대 100% / 디폴트옵션 등록 **N** / 입금예정상품 미등록
- PRODUCTS: 고유계정대 1억 8,000만 (2026-08-21 입금, 거래내역 사유 "과세이연/계약이전입금")
- ACTIVITY: 운용지시 없음 / 1개월 고유계정대 증감 +1억 8,000만
- PENSION: IRP 신규 2026-08-19 (퇴직용) / 퇴직급여 포함 Y (이연퇴직소득세 1,650만) / 연금개시요건 **미충족(55세 미만)** / 환급 처리 상태 미확인
- 상담이력: 2026-08-19 "운용은 당분간 생각해 보겠다"

**Business Knowledge Needed** — 미운용 판단 기준(1개월·입금사유); 디폴트옵션 적용은 **등록된 경우** 최초입금 후 2주 → 미등록이면 현금성 지속; 디폴트옵션 지정은 법적 의무(제도안내); 55세 미만 연금개시 불가·인출은 해지(퇴직소득세 전액); 중도인출 법정사유; 자금 사용시점에 따른 운용기간 설정; 과세이연 환급 전 지급 제한.

**Relevant Source Candidates** — SRC-002 (L50, L178), SRC-089 (적용 케이스 1, FAQ), SRC-003 (L706, CASE③ Step 5 "환급 전 제한"), SRC-024 (자금 성격→기간), SRC-037, SRC-087 (중도인출 사유)

**Expected Good Judgment**
- 현금성 100% 를 "입금 7일차 대기자금 가능성" 으로 해석하고, 미운용 확정은 하지 않는다.
- 즉시 관리 포인트는 상품이 아니라 **(a) 디폴트옵션 미등록 상태의 의미(제도안내: 의무·2주 후에도 자동 운용되지 않음)** 와 **(b) 자금 사용계획·시점 확인** 이다.
- 55세 미만 → 연금개시 불가, 지금 인출하면 해지·퇴직소득세 전액 부담 → "55세까지 유지할 자금인가, 그 전에 쓸 자금인가" 를 먼저 묻는다.
- 사용 시점이 확인된 뒤에야 운용기간에 맞는 **유형**(단기 원리금보장 vs 성향 내 장기 운용)을 선택지로 제시한다.
- 직원 다음 행동: [04-12-644] 입금사유 확인, 과세이연 환급 처리 상태([04-12-648]) 확인, 디폴트옵션 등록 안내(스타뱅킹 경로), 상담 예약.

**Critical Mistakes** — "장기 방치" 로 규정하고 리밸런싱 권유; 연금개시 가능하다고 안내; 디폴트옵션 미등록인데 "2주 후 자동 운용" 이라 안내; 위험중립 초과 상품 제시; 사용계획 확인 없이 3년제 상품 권유.

**Low-quality Behaviors** — 확인 질문이 "운용 계획 있으세요?" 수준으로 모호(사용 시점·55세 전 필요 여부를 묻지 않음); 디폴트옵션 의무 안내 누락; 고객이 "생각해 보겠다" 고 한 이력을 무시하고 즉시 권유 톤.

**Human Review Needed** — 디폴트옵션 등록 "의무" 를 Agent 가 고객에게 직접 안내하는 것이 제도안내 범위인지(권유 아님) 확인.

### GC-04 공격투자형 · 예금 100% · "원금손실 우려" 명시 (Negative)

**Primary Capabilities** — C2, C5, C10, C9

**Customer Input**

### GC-09 디폴트옵션 초저위험 보유 · 성향 공격투자형 상향 · 45세

### GC-10 연금개시 요건 충족 · 미개시 · 예금 만기 · "당분간 운용 지속" (Negative)

### GC-15 연금저축보험→IRP 이전 요청 · 52세 · 가입 3년 (실행 불가)

**Situation** — 52세 고객이 타사 연금저축보험(2023년 가입, 1,200만원)이 수익이 안 난다며 당행 IRP 로 합치고 싶다고 요청했다.

**Why Important** — 연금저축→IRP 이전은 **만 55세 & 가입 5년** 요건이 있어 현재 불가하다. "안 된다" 를 정확히 말하고, 대안을 과장 없이 안내하며, 해지 후 입금 같은 손해 경로를 권하지 않는지 검증한다 (SRC-043 2-2), SRC-070/079, SRC-009).

**Primary Capabilities** — C4, C7, C9

**Customer Input**
- BASIC: 만 52세 / 안정추구형
- 당행 IRP: 가입 2020-03 / 평가 4,000만 / 정기예금·GIC 100%
- 타사 연금저축보험: 가입 **2023-05** / 적립 1,200만 / 공시이율 2.x% / 해지환급금 미확인 / 연금개시 N
- 기타: 퇴직소득 없음(재직 중) / 세액공제: 연금저축 600만 + IRP 300만 구조로 납입 중
- 고객 발화: "보험은 수익이 안 나서 IRP 로 다 합치고 싶어요."

**Business Knowledge Needed** — 연금저축→IRP 이전 요건(55세 이상 & 가입 5년 경과, 퇴직소득 존재 시 제외); 요건 충족 예상 시점(2028-05 이후 & 55세); 연금저축 간 이전(연금저축펀드 등) 은 별도 경로(⚠ Source 근거 약함 → 확인 필요); 보험 해지 시 해지환급금 손실·세액공제분 추징(16.5%); 세액공제 900/600 합산 구조.

**Relevant Source Candidates** — SRC-043 (2-2)), SRC-070, SRC-079, SRC-009, SRC-075, SRC-003 (L441 CASE②), SRC-026 (F25:38)

**Expected Good Judgment**
- 현재 요건 미충족 → **이전 불가** 를 명확히, 충족 시점을 계산해 안내.
- 대안은 조건부·확인 필요 표시와 함께: (a) 요건 충족 시 이전 재검토, (b) 연금저축 간 이전 가능성은 상품·기관 확인 후, (c) 보험 유지 + 납입 배분 조정.
- 해지 후 IRP 입금은 손실(해지환급금)·추징이 있으므로 권하지 않고, 원한다면 손실 규모를 먼저 확인.
- 당행 IRP 자체는 별도로 점검 가능(안정추구형 내 만기 관리 등) — 단 이번 요청과 분리.

**Critical Mistakes** — 이전 접수 진행; 해지 후 입금 권유(손실·추징 미고지); 요건을 잘못 말함(5년만/55세만); 연금저축 간 이전을 확정적으로 안내(Source 확인 없이).

**Low-quality Behaviors** — "불가" 만 답하고 시점·대안 없음; 고객의 불만(수익) 에 대한 정보(공시이율 vs 대안) 없음.

### GC-16 "증권사로 옮기겠다" · 실물이전 접수 · 디폴트옵션·수협예금 보유

**Situation** — 49세 적극투자형 고객이 "ETF 실시간 거래가 안 되고 수수료도 무료라서" 증권사로 실물이전을 신청했다. 보유 상품 중 디폴트옵션 상품과 수협 정기예금은 실물이전이 불가해 현금화가 필요하다.

**Why Important** — 이탈 대응은 Source 분량이 가장 큰 영역이지만, 좋은 Agent 는 **사전체크(손실·불가 상품) → 경청 → 팩트 기반 안내 → 고객 결정 존중** 을 하고, 과장·비방·지연을 하지 않아야 한다 (SRC-003 §03-2, SRC-001 팩트체크, SRC-013/017/018, SRC-061/065/067).

**Primary Capabilities** — C7, C10, C9, C11

**Customer Input**
- BASIC: 만 49세 / 적극투자형 / 대면 개설 계좌 (가입자부담금 수수료 0.28%)
- IRP_SUMMARY: 평가금액 1억 3,000만 / ETF 42% / 디폴트옵션 27% / 저축은행 예금 19% / 수협 정기예금 12%
- PRODUCTS: RISE 미국나스닥100 ETF 3,000만 / RISE 미국S&P500 ETF 2,500만 / 디폴트옵션 「뿔려드림1」(정기예금 30 + TDF 70) 3,500만 / SBI저축은행 정기예금 1년 2,500만 (만기 2027-05, 3.4%) / 수협 정기예금 1년 1,500만 (만기 2027-01, 3.3%)
- EVENT: 계약이전(전출) 알림 2026-08-27 — **실물이전** 신청, 상대기관 ○○증권 / [06-AD-020] 실물이전 가능여부: ETF 가능, 디폴트옵션 상품 불가, 수협 정기예금 불가, 저축은행 정기예금 가능(⚠ 확인)
- 고객 발화 (전출 확인 전화): "ETF 실시간으로 못 사고팔고, 증권사는 수수료 무료라서요."

**Business Knowledge Needed** — 실물이전 조건(같은 유형·같은 상품·가능 상품)·불가 상품 현금화(중도해지 손실·운용 중단 기간); 디폴트옵션 보유 시 해지 필요; 상대기관 확인전화·거절 사유; 은행 ETF 체결 방식(3분 분할, 24시간 신청)·라인업 수(as-of); 수수료 사실(대면→비대면 전환 인하, 55세·연금개시 면제 조건)·타사 수수료 정책은 확인 후; 고객 결정 존중, 절차 지연 금지, 계열사 소개는 요청 시.

**Relevant Source Candidates** — SRC-003 (§03-2 사전체크·스크립트), SRC-001 (§Ⅱ-1 ETF 팩트, L248 ⚠), SRC-004, SRC-013, SRC-017, SRC-018, SRC-061, SRC-065, SRC-067, SRC-074, SRC-055 (⚠ KPI)

**Expected Good Judgment**
- 통화 전 사전체크를 먼저 구성: 이전 유형(실물), 불가 상품(디폴트옵션·수협 예금)의 현금화 손실·정기예금 중도해지 손실, ETF 매도 후 재매수 공백.

**Critical Mistakes** — 실물이전 전부 가능하다고 안내; 디폴트옵션·예금 현금화 손실 미고지; "우리도 실시간 거래 가능" 등 허위; 근거 없는 경쟁사 비교; 이전 절차 지연·방해; KPI(가중치·계열사 보전) 를 판단 근거로 언급.

**Low-quality Behaviors** — 이탈방어 스크립트를 그대로 재생산(사유 확인 없이 장점 나열); 부분 대안 없음; as-of 없이 라인업 수·순위 인용; 고객 결정권 언급 없음.

### GC-17 "TDF 하나 골라달라" · 34세 위험중립형

**Situation** — 34세 위험중립형 고객이 IRP 현금성자산 700만원을 TDF 로 운용하고 싶다며 "뭘 골라야 하느냐" 고 묻는다. 은퇴 예상 시기는 확인되지 않았다.

**Why Important** — 상품 추론의 대표 Case. TDF 는 빈티지 계산·운용사별 위험자산 비중·위험등급·H/UH·100% 예외 등 **선택 전 알아야 할 것** 이 많고, 성향↔펀드 위험등급 적합성 매핑이 Source 에 없어 단정 추천이 위험하다. 특정 상품 지목 대신 선택 기준을 제시하는지, 디폴트옵션 대안을 아는지 본다.

**Primary Capabilities** — C6, C5, C3, C9

**Customer Input**
- BASIC: 만 34세 (1992년생) / 위험중립형 (2026-06-01) / 스타뱅킹 이용 Y
- IRP_SUMMARY: 평가금액 2,400만 / 고유계정대 29% / 정기예금 38% / 채권형펀드 33% / 디폴트옵션 「알파드림2」(저위험)
- PRODUCTS: 고유계정대 700만 (2026-06-15 부담금, 무변동) / 시중은행 정기예금 900만 (만기 2027-06) / 키움더드림단기채 800만 (매우낮은위험)
- 고객 발화 (앱 상담 요청): "TDF 로 굴리고 싶은데 어떤 걸 골라야 하나요?"

**Business Knowledge Needed** — TDF 빈티지 = 출생연도 + 예상 은퇴연령(60세 가정 → 2052 → 2050/2055 중 선택); 같은 빈티지도 운용사별 위험자산 비중·위험등급 상이(2050: 67~80%); 성향 상한(위험중립형)과 펀드 위험등급 적합성(⚠ 매핑 Source 없음 → 부적합 확인 절차 가능성); 빈티지를 낮춰 위험 조절 가능; H/UH; TDF 100% 예외; 디폴트옵션 뿔려드림1(정기예금30+TDF70) 대안; 비대면 특정펀드 지목 유의; 매수는 본인 앱(성향 확인).

**Relevant Source Candidates** — SRC-090, SRC-094 (TDF 매트릭스), SRC-095 (위험등급), SRC-089 (뿔려드림), SRC-024, SRC-020, SRC-037 (⑤), SRC-002 (L293), SRC-001 (§Ⅱ-1 TDF)

**Expected Good Judgment**
- 먼저 확인: 예상 은퇴 시기, 관리 위임 vs 직접 관리 선호, 이 700만의 장기성.
- 선택 기준을 설명: 빈티지 계산 원리, 숫자가 클수록 위험자산↑, 운용사별 차이, 위험등급이 성향 범위 안인지 확인 필요, H/UH 의미 — **특정 1개 상품을 단정하지 않는다.**
- 위험중립형이 매수 가능한 등급인지 확인하는 절차(앱 매수 시 적합성 확인)를 안내하고, 등급이 높다면 빈티지를 낮추거나 뿔려드림1 같은 디폴트옵션 포트폴리오 대안을 유형으로 제시.
- 34세 장기 투자기간 → TDF 자체는 적합한 유형임을 인정(나이만으로 단정하지는 않음).
- 실행: 고객 본인 앱에서 매수; 채널이 비대면이면 특정 펀드 지목 지양.

**Critical Mistakes** — 나이만으로 특정 TDF2055 상품명 확정 추천; 위험중립형 상한을 넘는 등급을 적합성 확인 없이 권유; TDF 를 원금보장처럼 설명; TDF 에 70% 한도가 적용된다고 안내; 은퇴시기 확인 없이 결론.

**Low-quality Behaviors** — TDF 일반 설명만 하고 이 고객의 숫자(1992년생, 위험중립) 에 연결하지 않음; 운용사별 차이·위험등급을 언급하지 않음; 디폴트옵션 대안 없음; 고객이 앱에서 무엇을 하면 되는지 없음.

**Human Review Needed** — 투자성향↔펀드 위험등급 적합성 기준(부적합 확인서 절차 포함)의 공식 Source 확보 (Gate ②).
