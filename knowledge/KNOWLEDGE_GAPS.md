# Knowledge Gaps Registry (KG-xxx) — Knowledge Coverage State / Negative Evidence

- Status: **v1 (2026-08-31, DB-004 승인)**. Session B 소유.
- **KG는 일반 Knowledge가 아니다.** 기록 대상은 Knowledge Coverage의 경계(Negative Evidence): ① 무엇을 확인하려 했는가 ② 어디까지 확인했는가 ③ 무엇이 확인되지 않았는가 ④ 따라서 Agent가 무엇을 단정하면 안 되는가 ⑤ 필요 시 어디에서 추가 확인해야 하는가.
- `consume_text`는 Agent에게 **현재 Knowledge Coverage의 경계**를 전달하는 구조적 문면이다 — 새로운 판단 Rule·Case Expected 작성 용도가 아니며, "정답을 알려주는 Prompt"가 아니다. 의미 구조: `[확인되지 않음] / [확인된 범위] / [사용 경계] / [추가 확인]`.
- ID는 append-only Stable ID. 원천 확보 시 삭제하지 않고 `RESOLVED` + 해소 Knowledge ID를 연결한다.
- gap_type v1 어휘: `source_not_found`(원천 자체 부재) / `definition_not_available`(용어·지표는 실존하나 정의·산식 부재) / `official_source_not_found`(지식은 있으나 T1/T2 근거 부재 — T3/Public 단독) / `execution_path_unconfirmed`(실행 경로의 실존 미확인).
- A의 인용: knowledge_pack K-item으로 KG-ID 인용 가능 — consume_text가 K-item 본문이 된다. 어떤 Case에 어떤 KG를 동봉할지는 A/Human 몫.
