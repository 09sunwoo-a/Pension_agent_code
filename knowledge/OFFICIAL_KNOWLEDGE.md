- 확인·처리 위치: [04-10-099] 세금우대관련조회(저축종류 83-만기 ISA 전환, SRC-003 L495~497) / 창구 [01-12-213] 입금/입금예약(거래구분 'ISA 만기자금 입금', 입금가능금액 자동조회 — SRC-072) / StarBanking 전체메뉴 > 가입상품관리 > 퇴직연금 > 입금 > ISA만기자금 입금(영업일 03:00~19:00 — SRC-072). 화면 상세: SCR-014·SCR-015.

- 이전 의사 결과 처리(L966~990): 취소 시 — [72-01-801] 통화버튼 녹취 → [06-AD-080] 전출취소(해제) 실행 → CRM 등록. 고객 직접 취소 — 알림톡 [이전 미동의] 또는 StarBanking 메뉴 > 퇴직연금 > 연금이전 > 연금 가져오기 > 퇴직연금 이전 동의하기에서 [이전 미동의]. 이전 진행(방어 실패) 시 — 고객 의사 수용 + 의사확인 절차 안내: 1차 당일 18시 이후 Link 발송, 미응답 시 2차 익일 10시·14시 AI콜봇, **이전의사 확인기한 내 의사 미확인 시 계좌이체 자동 취소**(L990).

- 의사확인 시각·채널(18시 Link/익일 AI콜봇)은 2026-03 시점 운영 방식 — 변동 가능.
- 같은 절 내 KPI 보전(계열사 이전 실적 등) 서술은 Bank Objective — 추천사유 사용 불가(HD-7/G4). 이 항목은 절차·고지 사실만 담음.

### OK-003. 계약이전의 실물/현금 이전 구조 — '부분 이전' 절차 부재(부정 확인)·중도해지 손실 확인

| 필드 | 값 |

| authority | T2-InternalGuide(SRC-003·010·027) + T3-FieldTip(상세) |
| as_of | SRC-003 2026-03 / SRC-065 2025-10 / SRC-082 2026-07 |
| status | ACTIVE |
| delivered_for | REQ-011 |

| topics | 부분이전, 실물이전, 현금이전, 전액현금대체, 중도해지이율, F-010 |

**Content**:
- **부분 이전("계좌 내 일부 상품만 선택해 이전") 절차 = `현재 확보된 근거로 확인되지 않음`** (DB-003 §4 확정 상태 표기) — corpus 전체에서 절차 서술도, 명시적 불가 서술도 없음. 화면 Master(SRC-027, 화면 68종 색인)에도 해당 화면·메뉴 없음. 모든 계약이전·계좌이체 서술은 계좌 단위 이전을 전제. **이 미발견 사실을 "부분이전 불가능"으로 승격하지 않는다(Human Decision).**
- 실물이전 내 상품 단위 처리(부분 이전과 구별): 이전 가능 상품은 그대로 이전, 불가 상품(이전기관 전용 상품·당행 미취급 상품·디폴트옵션 상품 등)은 "해당 상품만 현금화되서 이전"(SRC-010 L51). 신청 후 [06-AD-020]으로 실물이전 가능/불가 상품 확인 → 고객이 **전체 이전의 수락/거절을 최종 결정**(SRC-010 L72~74 "신청 이후 실물이전이 가능한 상품을 확인하신 뒤에 최종 이전여부를 결정"; SRC-067 L114 "상품 목록 확인 후 수락 또는 거절").
- 현금이전: 중도해지 또는 환매로 인한 손실/불이익 확인이 필수 체크 항목(SRC-003 L869). 현금성자산만 보유 시 실물이전 불가 → 현금이전으로 재신청(SRC-065 L22).
- 디폴트옵션 상품과 이전(SRC-098 L188~212, 2026-08 추가): DO 상품은 실물이전 비대상 — 타사 이전 시 현금화 매도 방식으로만 이전 가능("타사 이전이 '불가능' 한 것은 아닙니다"). 고객이 실제 이전 시 현금화 매도됨을 **사전에 충분히 설명하지 않으면 불만 발생 가능** — 설명 의무 준수 항목으로 명시("디폴트옵션은 타사 이전 시 실물이전이 불가능 & 매도 후 현금 이전만 가능하다는 점을 사전 안내").
- 정기예금 중도해지이율: **구체 이율 수치·산식은 corpus에 없음.** 확인 도구 — ① KB-WiseNet > Info Zone > 연금(퇴직연금) > 정기예금 중도해지&리밸런싱 계산기(참고용 명시, SRC-003 L881) ② [04-12-642] 연계메뉴 '정기예금 중도해지 예상조회'(만기전이율·중도해지이율·만기가치 vs 중도해지평가액 비교 — SRC-082 L45·L50). 중도해지이율이 수수료율 합계(운용관리+자산관리)보다 낮은 상태에서 해지 시 원금에서 수수료 차감 지급 + 지급신청일 포함 3영업일 경과 후 지급 가능성 사전 안내 필요(SRC-043 L26, T3).

**Limitation**:
- 부분 이전 "불가"의 공식 확정 근거도 없음 — 부재는 corpus 한계일 수 있으므로 **제도적 불가로 단정 금지**. Case 설계·판단에서 "부분 이전 가능/불가"를 사실로 쓰려면 별도 공식 확인 필요.
- 중도해지이율 수치는 시스템 조회로만 확인 — 확정 계산은 Agent Scope 밖(HD-1).
- 수수료 차감·3영업일 케이스는 T3 단독 — Operational Check Needed.
